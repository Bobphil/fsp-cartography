# FSP-VR-HORIZON-PERCEPTION-PILOT-1

## Framework-Naive Human Perception Pilot for Retained-Horizon Compression

**Status:** NON-DEPLOYED HUMAN-PERCEPTION PILOT — VERSION 1.0  
**Test object:** FSP-VR-MAATHAI-FIELD-3  
**Primary ambiguity:** Does retained-horizon compression preserve a distant possibility as presently inspectable, or is it misread as temporally nearer / more likely / recommended?  
**Cohort:** first five framework-naive participants  
**Data policy:** local-only observer capture; no automatic network submission.

# 1. Primary Research Question

After:

**ACCELERATE → inspect distant path → pin → FREEZE**

does a framework-naive participant understand the compressed retained-horizon marker as:

> **still possible later, not reachable now because conditions remain unresolved, but retained for present inspection**

rather than as:

- closer in time;
- more likely;
- more feasible;
- recommended;
- historically destined?

# 2. Construct Being Tested

The pilot tests whether users distinguish:

1. **Temporal distance** — how much change/time separates present from possibility.
2. **Conditional distance** — how many prerequisites remain unresolved.
3. **Attentional availability** — whether the possibility remains available for inspection now.

FIELD-3 intentionally changes attentional availability while attempting not to imply changes in temporal or conditional distance.

# 3. Freeze Rule

Pilot version:

**FSP-VR-HORIZON-PERCEPTION-PILOT-1.0**

Do not change:
- FIELD-3 geometry;
- participant prompts;
- observer questions;
- scoring;
- error-code meanings

during participants 1–5.

If a material defect is found:
- stop cohort;
- increment version;
- restart.

# 4. Participant Eligibility

Prefer people who:
- have not worked on FSP;
- have not seen the design rationale;
- do not know the intended horizon-compression interpretation.

No philosophy, VR, or historical expertise is required.

# 5. Participant Orientation

Use only:

> You are looking at possible things that might become possible from a historical situation. Some are available sooner; others require more things to change first. Explore the display as it seems natural to you.

Do not explain:
- FSP;
- horizon retention;
- inspection compression;
- the intended interpretation;
- the correct answer.

# 6. Fixed Trial Sequence

## Phase A — Freeze baseline

Start in FREEZE.

Ask:

> What possibilities seem available from here?

Purpose:
establish the participant's spontaneous reading of near / present reachability.

## Phase B — Accelerate

Participant presses ACCELERATE.

Ask:

> What changed?

Do not prompt with “future,” “time,” “likelihood,” or “possibility.”

## Phase C — Inspect distant advocacy path

Participant inspects **Publicly advocate for change**.

Ask:

> Why does this possibility seem farther away than the ones near the center?

## Phase D — Pin and Freeze

Participant pins advocacy, then presses FREEZE.

Immediately ask:

> What happened to the advocacy possibility?

Then ask, in order:

1. Did anything about the possibility itself change?
2. Is it now easier to reach, harder to reach, or unchanged?
3. Is it now more likely, less likely, or unchanged?
4. Why do you think it moved visually?
5. Without accelerating again, what would have to change before it became more reachable?

# 7. Transfer Check

After the retained-horizon questions, present three abstract cases:

**A.** A possibility available now with present resources.  
**B.** A possibility requiring several missing conditions.  
**C.** A possibility for which we know very little.

Ask:

> Which is most like the retained advocacy marker?

Expected interpretation:
**B**, possibly with some C-like uncertainty where unknown conditions remain.

This is a transfer check, not a memorization question.

# 8. Five Scored Distinctions

Each receives 0–2.

## D1 — Distant possibility remains identifiable

0 — cannot identify it  
1 — identifies after prompt  
2 — spontaneously identifies retained advocacy possibility

## D2 — Compression ≠ temporal nearness

0 — says it became closer in time  
1 — uncertain / mixed  
2 — clearly says visual compression did not change temporal remoteness

## D3 — Compression ≠ probability increase

0 — says compression makes it more likely  
1 — uncertain / mixed  
2 — clearly says likelihood did not increase merely because marker moved

## D4 — Missing contingencies still matter

0 — missing conditions disappear from interpretation  
1 — remembers some conditions  
2 — clearly preserves unresolved / absent / unknown conditions

## D5 — Retained marker = present attentional availability

0 — does not understand retained-inspection function  
1 — approximate understanding  
2 — clearly explains that the system is keeping the distant possibility available to inspect from the present

Maximum: **10**

# 9. Primary Pass Threshold

First-pass cohort criterion:

- at least **4 of 5 participants score 8/10 or better**;
- no more than **1 participant** commits a temporal-nearness error;
- no more than **1 participant** commits a probability-increase error;
- no more than **1 participant** interprets the retained marker as recommendation / historical destiny.

This is a product-learning threshold, not an inferential statistical claim.

# 10. Error Codes

**HP-TIME-NEAR**  
Compression interpreted as making future temporally nearer.

**HP-PROB-UP**  
Compression interpreted as making future more likely.

**HP-FEAS-UP**  
Compression interpreted as making action easier / more feasible merely because marker moved.

**HP-RECOMMEND**  
Marker interpreted as recommendation / preferred path.

**HP-DESTINY**  
Marker interpreted as historical inevitability.

**HP-CONTINGENCY-LOSS**  
Unresolved prerequisites no longer recognized after Freeze.

**HP-IDENTITY-LOSS**  
Participant cannot identify what retained marker refers to.

**HP-ATTN-FAIL**  
Participant does not understand why the distant path remains visible.

**HP-PANEL-DEPENDENCE**  
Correct interpretation requires textual side-panel support rather than field geometry.

# 11. Interpretation Classes

## P1 — Strong horizon interpretation

Participant explains, in ordinary language, approximately:

> It has not actually become closer or more likely; the display is keeping it visible while I focus on the present.

## P2 — Partial horizon interpretation

Understands it remains later / conditional but cannot explain why it moved.

## P3 — Temporal-nearness error

Compression interpreted as shortening temporal distance.

## P4 — Probability / recommendation error

Compression interpreted as increased likelihood, feasibility, recommendation, or destiny.

# 12. Scaffold Escalation Policy

Pilot 1.0 tests **geometry first**.

Do not initially add explanatory text such as:
- “still distant”;
- “likelihood unchanged”;
- “retained for inspection.”

If Pilot 1.0 fails, next conditions may test:

**Condition B — minimal cue**
> Still distant · retained for inspection

**Condition C — explicit firewall**
> Position changed for inspection only; temporal distance and likelihood have not changed.

Prefer the least verbal cue that reliably resolves the ambiguity.

# 13. Observer Procedure

Observer should:
- read orientation verbatim;
- avoid explaining interface terminology;
- record participant wording as closely as possible;
- score only after the participant answers;
- note spontaneous versus prompted understanding;
- record all error codes that occur.

# 14. Local Data Fields

For each participant:

- participant code;
- pilot version;
- date;
- prior FSP exposure: yes/no;
- D1–D5 scores;
- error codes;
- spontaneous wording;
- transfer choice A/B/C;
- observer notes;
- total score.

No names are required.

# 15. Claim Ceiling

A five-person pilot can identify recurrent misreadings and interface problems.

It cannot establish:
- population prevalence;
- statistical efficacy;
- general learning transfer;
- VR effectiveness;
- long-term critical-thinking improvement.

If results are intended for formal publication or generalizable human-subject research, institutional ethics / IRB requirements should be checked before recruitment.

# 16. Stop / Revise Rules

Stop and revise before participant 5 if:
- 2 participants make HP-TIME-NEAR;
- 2 participants make HP-PROB-UP;
- 2 participants make HP-RECOMMEND or HP-DESTINY;
- 3 participants show HP-PANEL-DEPENDENCE;
- a material interface defect changes what participants can see.

# 17. Success Meaning

A successful first pilot would support only:

> Framework-naive users can often distinguish retained attentional availability from temporal/probabilistic nearness in this bounded visual interaction.

It would not yet validate the broader FSP-VR prosthetic.

# 18. Next Decision

If PASS:
- proceed to a second human visual trial focused on present-vs-horizon comparison and scaffold fading.

If FAIL:
- do not add historical states;
- revise retained-horizon grammar before WebGL / 3D.
