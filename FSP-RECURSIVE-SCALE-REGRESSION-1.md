# FSP-RECURSIVE-SCALE-REGRESSION-1

## Four-Case Portability Test: Bat Echolocation, Planaria Adaptation/Regeneration, DESI Astronomy Measurement, and Institutional Reporting

**Status:** EXECUTABLE REGRESSION REPORT — VERSION 1  
**Parent architecture:** FSP-RECURSIVE-SCALE-ARCHITECTURE-1  
**Purpose:** Test whether one recursive-scale relation grammar survives four sharply different domains without metaphorical strain.  
**Cases:** biological sensory navigation; biological adaptation/regeneration; astronomical measurement; institutional reporting and control.  
**Primary question:** Can the same typed relations—constitution, enablement, constraint, modulation, coordination, translation, evidence, recursion, access formation, detection, and scale bridging—remain useful while domain-native ontology stays intact?

---

# 1. Regression Rule

The architecture passes only if all four cases can be encoded with the same **relation grammar** while preserving domain-specific entities and avoiding the following collapses:

- lower-scale realization → exhaustive explanation;
- higher-scale organization → independent substance;
- local registration → whole-system detection;
- cross-scale correlation → explanatory identity;
- emergence label → explanation;
- institutional aggregation → collective phenomenality;
- instrument output → human direct perception;
- behavioral success → phenomenal identity.

The regression is not a search for identical mechanisms.

It is a test of **formal portability without ontological flattening**.

---

# 3. Case A — Bat Echolocation and Acoustic Cognitive Mapping

## 3.1 Empirical anchor

Goldshtein et al. (Science, 2024) reported kilometer-scale map-based navigation in Kuhl's pipistrelle bats using echolocation alone, with navigation improved when vision was also available. A large-scale echolocation model supported the availability of environmental acoustic structure for navigation.

Subsequent hippocampal work reported egocentric object-distance and allocentric object-location coding during active sonar tracking, with degradation of the spatial code when tracking ceased.

## 3.2 Domain-native scales

- acoustic environment;
- ear / cochlear / receptor processes;
- neural temporal and spectral integration;
- hippocampal spatial representation;
- sensorimotor control;
- whole-organism flight and call production;
- ecological navigation.

## 3.3 ScaleRelationGraph

```text
ACOUSTIC ENVIRONMENT
  --INFORMATION / ACCESS CONDITIONS-->
EAR / RECEPTOR PROCESSES
  --ENABLES-->
NEURAL TEMPORAL / SPECTRAL INTEGRATION
  --ENABLES / CONSTITUTES-->
SPATIAL REPRESENTATION
  --ENABLES-->
SENSORIMOTOR CONTROL
  --ENABLES-->
WHOLE-ORGANISM NAVIGATION
  --MODULATES-->
CALL PRODUCTION / FLIGHT PATH
  --TRANSFORMS-->
ACOUSTIC ENVIRONMENT
```

This is recursive, not linear.

## 3.4 RecursiveScaleLoop

```text
call + movement
→ changed echo field
→ receptor registration
→ neural integration
→ spatial discrimination
→ navigation action
→ new call + movement
```

**PASS:** active access is naturally represented.

## 3.5 DetectionChain

```text
ultrasonic return
→ local receptor registration
→ temporal/spectral integration
→ spatial discrimination
→ task-relevant object/location detection
→ navigation behavior
```

**PASS:** the grammar blocks the claim that a receptor "detects the landmark" in the same sense the organism does.

## 3.6 ScaleBridgeRecord

Example bridge:

```text
sourceScale: hippocampal population
targetScale: organism navigation
bridgeRelation: EVIDENCES / ENABLES
bridgeAssumption: neural coding contributes to spatial task organization
claimCeiling: neural representation ≠ phenomenal spatial identity
```

**PASS with ceiling.**

## 3.7 EmergenceRecord

Best fit:

- **ACCESS_EMERGENCE:** whole-organism acoustic spatial access depends on organized receptor, neural, motor, and ecological relations.
- **CAPABILITY_EMERGENCE:** kilometer-scale navigation is not attributable to one local detector.
- **CONSTRAINT_EMERGENCE:** whole-organism task state modulates lower-scale sensing through active tracking and call production.

**PASS.**

## 3.8 EvidenceBridgeGraph

Evidence nodes:

- field trajectories;
- sensory manipulation;
- acoustic modeling;
- neural recordings;
- tracking state.

Relations:

- behavioral ↔ model calibration;
- active tracking ↔ neural representation;
- vision manipulation ↔ multimodal navigation.

**PASS.**

## 3.9 Remainders

- EMPIRICAL: exact integration mechanisms across sensory modalities;
- SCALE: complete bridge from local neural coding to whole-route navigation;
- PHENOMENAL: qualitative character of acoustic spatial experience;
- TRANSLATIONAL: human visualization of acoustic structure.

**PASS:** typed remainder prevents the Nagelian gap from swallowing all unfinished science.

## 3.10 Case verdict

**CLEAN PASS.**

No domain-local scale object is needed.

The architecture is strengthened by requiring:
- active sensing;
- scale-relative detection;
- phenomenal claim ceiling.

# 4. Case B — Planaria BaCl2 Adaptation and Regeneration History

## 4.1 Empirical anchor

In the 2019 BaCl2 study, Dugesia japonica exposed to 1 mM barium chloride showed anterior degeneration, then regenerated heads tolerant of the same environment. Transcriptomic and pharmacological work implicated altered ion-channel and physiological regulation. Tolerance was lost after time back in normal water.

A 2026 transcriptomic study further found that recent regeneration history strongly affected global expression profiles and that different regenerative contexts produced different molecular strategies.

## 4.2 Domain-native scales

- ion-channel / membrane physiology;
- transcriptional regulation;
- cellular physiology;
- tissue patterning / head regeneration;
- organism-level morphology and movement;
- environmental BaCl2 exposure;
- regeneration history.

## 4.3 ScaleRelationGraph

```text
BaCl2 ENVIRONMENT
  --CONSTRAINS / PERTURBS-->
ION / MEMBRANE PHYSIOLOGY
  --MODULATES-->
TRANSCRIPTIONAL REGULATION
  --COORDINATES-->
CELLULAR PHYSIOLOGY
  --CONSTITUTES / ENABLES-->
TISSUE REGENERATION
  --ENABLES-->
ORGANISM-LEVEL TOLERANCE
  --FEEDS BACK THROUGH SURVIVAL / EXPOSURE-->
CELLULAR + TRANSCRIPTIONAL STATE
```

## 4.4 RecursiveScaleLoop

```text
environmental stress
→ physiological disruption
→ tissue degeneration
→ regenerative reorganization
→ altered transcription / physiology
→ organism-level tolerance
→ continued exposure under new organism state
→ revised cellular regulation
```

**PASS**, with an important qualification:

The loop is empirically supported at several points, but the exact direction and mechanism of every cross-scale edge is not known.

The formalism represents that uncertainty through bridge-specific remainder rather than filling it with "emergence."

## 4.5 EmergenceRecord

Best fit:

- **CAPABILITY_EMERGENCE:** BaCl2 tolerance is an organism-level capability not captured by any single transcript.
- **STRUCTURAL_EMERGENCE:** regenerated head organization.
- **CONSTRAINT_EMERGENCE:** organism/tissue state changes which lower-level physiological transitions remain viable.
- **ACCESS_EMERGENCE:** not primary here; using this label would strain the case.

**PASS because the architecture permits omission of irrelevant emergence types.**

This is important: not every case must instantiate every subtype.

## 4.6 Assembly history

The 2026 work makes the history axis essential.

```text
present phenotype
+ regeneration history
→ different transcriptomic state
→ potentially different future response structure
```

**STRONG PASS** for integration with `AssemblyTrace`.

This validates:

> Same present morphology ≠ same assembly history ≠ same future possibility structure.

## 4.7 DetectionChain

The organism is not primarily a sensory-navigation case.

A forced "detection" story would be metaphorical.

The legitimate chain is narrower:

```text
physiological perturbation
→ cellular / tissue response
→ measurable molecular changes
→ investigator detection
```

The biological system's "detection of stress" should not be asserted unless the relevant regulatory sensing mechanism is specified.

**PASS BY DISCIPLINE:** the architecture correctly allows `DetectionChain` to be non-central rather than forcing it.

## 4.8 ScaleBridgeRecord

Example:

```text
sourceScale: transcriptomic / physiological
targetScale: organism tolerance
bridgeRelation: ENABLES / EVIDENCES
claimCeiling: differential expression ≠ complete mechanism of tolerance
```

**PASS.**

## 4.9 EvidenceBridgeGraph

Evidence nodes:

- morphology;
- time course;
- RNA-seq;
- qPCR;
- pharmacological perturbation;
- reversal after water recovery;
- regeneration-history transcriptomics.

**PASS.**

## 4.10 Remainders

- MECHANISTIC: exact causal organization producing tolerance;
- SCALE: molecular-to-organism bridge;
- HISTORICAL: which retained traces of regeneration history remain functionally active;
- MODEL: alternative regulatory explanations;
- UNKNOWN: possible non-transcriptional physiological mechanisms.

**PASS.**

## 4.11 Case verdict

**CLEAN PASS WITH ONE IMPORTANT NEGATIVE RESULT.**

The formal grammar survives because it does **not** require sensory-access language where it does not belong.

This is evidence against metaphorical overextension.

# 5. Case C — Astronomy Measurement: DESI Spectroscopic Pipeline

## 5.1 Empirical / technical anchor

DESI's spectroscopic pipeline transforms observations into wavelength- and flux-calibrated spectra, with variance, masks, and spectral resolution, and then produces classified targets, redshift estimates, uncertainties, and confidence levels.

This is a useful non-biological test because it contains multiple physical and representational scales but no biological emergence requirement.

## 5.2 Domain-native scales / stages

Here "scale" is partly physical and partly representational.

That itself tests the formalism.

- astronomical source;
- emitted / transmitted radiation;
- telescope / fiber / detector interaction;
- detector pixel response;
- calibrated spectrum;
- fitted spectral features;
- redshift estimate;
- catalog-level population representation;
- cosmological inference.

## 5.3 ScaleRelationGraph

```text
ASTRONOMICAL SOURCE
  --PHYSICAL PROPAGATION-->
RADIATION AT INSTRUMENT
  --DETECTOR INTERACTION-->
PIXEL / INSTRUMENT RESPONSE
  --TRANSLATES / CALIBRATES-->
SPECTRUM
  --COMPUTATIONAL TRANSFORMATION-->
FEATURE / REDSHIFT FIT
  --AGGREGATES / EVIDENCES-->
CATALOG
  --EVIDENCES-->
COSMOLOGICAL CLAIM
```

## 5.4 RecursiveScaleLoop

The target system itself need not exhibit strong recursion relevant to the measurement.

But the **inquiry system** does:

```text
instrument design
→ observations
→ calibration
→ model / pipeline revision
→ new observing strategy
→ new observations
```

**PASS:** the target/inquiry recursion distinction is necessary and useful.

## 5.5 EmergenceRecord

Forcing "emergence" onto calibrated spectra or redshift catalogs would be misleading.

The proper relation types are:

- TRANSLATES;
- AGGREGATES;
- EVIDENCES;
- CALIBRATES.

**PASS BY NON-USE.**

This is a critical portability result:

> The recursive-scale formalism does not require emergence language to apply.

## 5.6 DetectionChain

```text
incoming photons
→ detector response
→ digitized counts
→ calibration
→ spectral feature extraction
→ redshift classification / estimate
→ human-accessible catalog result
```

**STRONG PASS.**

This cleanly distinguishes:

- detector registration;
- computational discrimination;
- scientific evidence;
- human mediated access.

## 5.7 ScaleBridgeRecord

Examples:

### Detector → spectrum

```text
bridgeRelation: TRANSLATES / CALIBRATES
```

### Spectrum → redshift

```text
bridgeRelation: EVIDENCES
bridgeAssumptions: spectral model / line identification / fitting procedure
```

### Redshift catalog → cosmological claim

```text
bridgeRelation: EVIDENCES
bridgeAssumptions: survey selection + statistical / cosmological model
```

**STRONG PASS.**

## 5.8 EvidenceBridgeGraph

This case shows why "evidence at one scale ≠ evidence for every adjacent-scale claim."

A calibrated spectrum is evidence for a redshift claim under a model; a redshift catalog is evidence for population/cosmological claims under additional selection and model assumptions.

**STRONG PASS.**

## 5.9 Remainders

- CALIBRATION / MODEL remainder;
- TRANSLATIONAL remainder across pipeline stages;
- SCALE remainder between source-level measurement and cosmological inference;
- EMPIRICAL uncertainty;
- no PHENOMENAL remainder.

**PASS.**

## 5.10 Case verdict

**CLEAN PASS AND IMPORTANT GENERALIZATION.**

The architecture survives outside biology, but one amendment is needed:

> "Scale" must include **representational / measurement aperture** as well as physical organization level.

This is not metaphorical if explicitly typed.

Recommended subtype:

```text
ScaleKind = {
  PHYSICAL,
  ORGANIZATIONAL,
  TEMPORAL,
  SPATIAL,
  REPRESENTATIONAL,
  INSTITUTIONAL
}
```

This is a genuine cross-domain augmentation.

# 6. Case D — Institutional Reporting and Control

## 6.1 Case status

This is an explicitly **synthetic structural case**, not an empirical claim about one named institution.

Scenario:

A service organization receives local incident reports. Local staff classify events. Aggregated metrics are transmitted to management. Management changes policy or resource allocation. Those changes alter future local reporting behavior and event rates.

## 6.2 Domain-native scales

- individual event;
- local actor / reporter;
- local classification unit;
- aggregated reporting system;
- management / governance layer;
- organizational policy;
- changed local practice.

## 6.3 ScaleRelationGraph

```text
LOCAL EVENT
  --REPORTED BY-->
LOCAL ACTOR
  --TRANSLATED / CLASSIFIED-->
LOCAL RECORD
  --AGGREGATED-->
INSTITUTIONAL METRIC
  --EVIDENCES-->
MANAGEMENT MODEL
  --AUTHORIZES / CONSTRAINS-->
POLICY / RESOURCE CHANGE
  --MODULATES-->
LOCAL PRACTICE
  --CHANGES-->
FUTURE EVENTS + FUTURE REPORTING
```

## 6.4 RecursiveScaleLoop

```text
local behavior
→ aggregate pattern
→ institutional interpretation
→ policy constraint
→ changed local behavior
→ new aggregate pattern
```

**STRONG PASS.**

This is structurally recursive without requiring biological mechanisms.

## 6.5 EmergenceRecord

Potentially legitimate:

- **STRUCTURAL_EMERGENCE:** aggregate organizational pattern not visible from one report.
- **CAPABILITY_EMERGENCE:** institution can coordinate resources beyond any single reporter.
- **CONSTRAINT_EMERGENCE:** policy changes lower-level action space.

But:

- no PHENOMENAL emergence;
- no claim that the institution "perceives" literally unless access is explicitly defined functionally.

**PASS WITH FIREWALL.**

## 6.6 AccessRelation

Institutional access is mediated through reporting channels.

```text
event
→ report
→ classification
→ aggregation
→ managerial representation
```

This validates the analogy to a social access architecture **only if it remains functional**.

> Institutional access architecture ≠ biological sensing by identity.

**PASS.**

## 6.7 DetectionChain

A management system may "detect" a threshold event only in a criterion-relative functional sense:

```text
local event records
→ aggregate metric
→ threshold crossing
→ alert
```

This is legitimate under the pressure-audit definition of detection because conscious awareness is not required.

**PASS.**

## 6.8 ScaleBridgeRecord

Example:

```text
sourceScale: local reports
targetScale: organizational risk claim
bridgeRelation: EVIDENCES / AGGREGATES
bridgeAssumptions: reporting completeness, classification validity, dependency structure
```

**STRONG PASS.**

## 6.9 EvidenceBridgeGraph

Critical dependencies:

- multiple reports may share a common source;
- under-reporting can distort aggregate metrics;
- classification rules can alter apparent prevalence;
- policy changes can alter reporting itself.

Thus the evidence system participates in the target dynamics.

**STRONG PASS.**

## 6.10 Remainders

- EMPIRICAL: unreported events;
- TRANSLATIONAL: classification loss;
- MODEL: aggregate metric vs underlying process;
- AUTHORIZATION: what management may do;
- NORMATIVE: whether the policy is justified;
- HISTORICAL: effects of prior policy and reporting culture.

**PASS.**

## 6.11 Case verdict

**CLEAN PASS WITH AN ONTOLOGY FIREWALL.**

The relation grammar travels.

The ontology does not:

> institution ≠ organism  
> institutional detection ≠ phenomenal awareness  
> higher-level coordination ≠ composite subject

# 8. Metaphorical-Strain Audit

A cross-domain object fails if it survives only by stretching ordinary words beyond defensible meaning.

## 8.1 "Emergence"

- Bat: natural and discriminating.
- Planaria: natural and discriminating.
- DESI: generally unnecessary.
- Institution: usable for structural/capability/constraint emergence if carefully bounded.

**Result:** PASS only because emergence is optional and typed.

If every scale transition were called emergence, the architecture would FAIL.

## 8.2 "Detection"

- Bat: biological detection at multiple scales.
- Planaria: use cautiously; investigator detection is clearer than organism "stress detection" unless a sensing mechanism is specified.
- DESI: technically precise detector registration.
- Institution: criterion-relative functional detection works.

**Result:** PASS because DetectionRecord is role- and criterion-relative.

## 8.3 "Access"

- Bat: organism-relative active access.
- Planaria: not central unless specific sensing/regulatory access is identified.
- DESI: instrument/computational/human-mediated access.
- Institution: reporting-mediated functional access.

**Result:** PASS because AccessRelation is route-typed and does not imply awareness.

## 8.4 "Scale"

- Bat/Planaria: physical + organizational.
- DESI: physical + representational + inferential.
- Institution: organizational + institutional.

**Result:** PASS WITH AUGMENTATION: scale kind must be typed.

# 9. New Pressure Discovered by the Regression

The architecture survives all four cases, but the regression exposes four additions/refinements.

## 9.1 ADD / SUBTYPE — ScaleKind

```text
ScaleKind = {
  PHYSICAL,
  ORGANIZATIONAL,
  TEMPORAL,
  SPATIAL,
  REPRESENTATIONAL,
  INSTITUTIONAL
}
```

Reason: DESI demonstrates that some legitimate scale transitions are representational/inferential rather than compositional levels.

## 9.2 ADD — RelationDomain

Each ScaleRelation should declare whether it is:

```text
TARGET_SYSTEM
INQUIRY_SYSTEM
COUPLED_TARGET_INQUIRY
```

Reason: astronomy often places recursion mainly in the inquiry system; biology may contain both.

## 9.3 SUBTYPE — EmergenceStatus

```text
REQUIRED
SUPPORTED
OPTIONAL_DESCRIPTION
NOT_APPLICABLE
CONTESTED
```

Reason: the grammar must represent non-use of emergence as a positive result.

## 9.4 ADD / FIELD — BridgeBurden

A ScaleBridgeRecord should specify how much inferential work crosses the bridge:

```text
BridgeBurden = {
  identityAssumption,
  mechanismAssumption,
  calibrationAssumption,
  aggregationAssumption,
  translationAssumption,
  statisticalAssumption,
  normativeAssumption
}
```

Reason: DESI and institutional reporting show that a bridge may be technically valid while carrying very different kinds of assumptions.

# 10. Core-Promotion Recommendation

## 10.1 Promote toward FSP Core / canonical-support

The four-case regression strongly supports promotion of:

- `ScaleRelation`
- `ScaleRelationGraph`
- `ScaleBridgeRecord`
- `EvidenceBridgeGraph`
- `TargetBinding`
- typed `RemainderRecord`
- typed `ConstraintRecord`
- `TranslationTopology`
- target-vs-inquiry recursion distinction

Why:

These survive all four cases and remain useful even when emergence, biology, or phenomenality are absent.

## 10.2 Promote cautiously / retain as canonical-support candidate

- `RecursiveScaleLoop`
- `DetectionChain`
- scale-indexed `AccessRelation`
- scale-indexed `DetectionRecord`

Why:

Portable, but not every inquiry requires them.

## 10.3 Keep experimental / domain-local

- `EmergenceRecord` as a specialized typed object;
- `OrganismEnvironmentLoop`;
- phenomenal bridge machinery;
- biological access-emergence subtypes.

Why:

Useful and coherent, but not required in astronomy and only partly required institutionally.

# 13. Core Claim After Regression

The four-case test supports a stronger but still bounded claim:

> **FSP's recursive-scale architecture is portable across biological, scientific-measurement, and institutional domains when treated as a typed relation grammar rather than a universal hierarchy of levels. It can represent constitution, constraint, coordination, access, detection, translation, evidence, and recursion while allowing domain-native mechanisms and ontologies to remain distinct.**

The regression does **not** support:

> all domains share one emergence mechanism.

Nor:

> every higher-scale pattern is emergent.

Nor:

> every inquiry requires a multiscale explanation.

The portability lies in the grammar of governed relations.
