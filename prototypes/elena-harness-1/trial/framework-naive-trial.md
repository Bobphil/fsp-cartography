# Framework-Naive Browser Trial

## Purpose
Test whether a user who has not learned FSP terminology can perceive the constitutional distinctions embedded in the Elena harness.

## Instructions to facilitator
1. Do not explain PRF, NUI, CNS, standing types, Corrigibility Reserve, or REOPEN before the trial.
2. Ask the participant to use Guided mode and move through all twelve states.
3. Encourage ordinary-language think-aloud comments, but do not correct them during exploration.
4. After State 12, use the nine questions in the browser's “Naive trial” dialog.
5. Record observable confusion separately from incorrect answers.

## Core observations
- Does the participant distinguish Elena from the chart?
- Does the participant notice that 0.81 changes institutional status at the threshold?
- Does the participant resist treating the model as an authority source?
- Does the participant treat standing as function-relative rather than a rank?
- Does the participant perceive Authorial Return and Consequential Return as different?
- Does the participant understand that a received error report may not yet change anything?
- Does the participant reopen relevant material without trying to restart the entire case?

## PASS criterion for a future actual human trial
A participant need not use FSP vocabulary. A provisional PASS requires correct ordinary-language grasp of at least 7/9 post-trial questions with no critical constitutional reversal (e.g. “the model can authorize sedation” or “Return means the system is already fixed”).

## Current build status
The browser contains the trial instrument, but no actual independent framework-naive human trial has yet been run. Do not report this as empirical validation.
