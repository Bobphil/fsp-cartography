# FSP-REVISION-1

## Revision-Target Grammar, Auxiliary/Theory/Task Change Operators, Neptune–Vulcan Comparator, Minimal-Mutilation Audit, and Revision-Choice Claim Ceiling

**Status:** First revision-governance branch built on the frozen TRANSLATION base  
**Boundary:** TRANSLATION-12 remains frozen; no human-validation claims are changed.

## 1. Purpose

The Translation program established how divergent frameworks, auxiliaries, tasks, and remainders can be represented and reopened.

REVISION-1 asks the next question:

> Once reopening is warranted, what exactly can be revised?

The answer must be richer than "change the theory" or "change an auxiliary."

The build therefore formalizes revision targets, change operators, comparative audits, and an explicit ceiling on what the system may conclude from preservation cost.

## 2. Revision targets

The first grammar distinguishes:

- EVIDENCE_ASSESSMENT
- AUXILIARY
- WARRANT
- BACKGROUND
- CLAIM_CEILING
- TASK
- ONTOLOGY
- FRAMEWORK

These targets are not assumed exhaustive.

They are the smallest useful set inherited from the current FSP translation architecture.

## 3. Revision operators

A revision may:

- remove commitments;
- add commitments;
- replace task text;
- replace claim-ceiling text.

Operations are typed by target so that an auxiliary repair cannot silently masquerade as a framework replacement.

The result carries both:

- the before/after states;
- the dimensions actually changed.

## 4. Minimal mutilation as audit, not rule

For each revision candidate, FSP records:

- changed-item count;
- preserved-item count;
- unresolved anomalies;
- new liabilities;
- empirical status;
- explanatory gains;
- preservation ratio.

The preservation ratio is called a **minimal-mutilation score**.

It is not a recommendation score.

The system may say:

> this candidate preserves more represented commitments.

It may not say:

> therefore this candidate is the uniquely rational revision.

## 5. Neptune comparator

The Uranus anomaly is represented with a Newtonian working framework and an auxiliary assumption that the relevant gravitating bodies are adequately represented.

The Neptune-style repair changes the auxiliary:

```
known bodies adequately represented
->
additional unknown planet may perturb Uranus
```

The framework remains Newtonian.

The historical success of the prediction/discovery trajectory gives this repair a supported empirical status in the comparator.

The important FSP result is:

- small represented revision;
- anomaly resolved;
- no need to infer ontological uniqueness;
- successful repair strengthens the candidate without proving the retained framework uniquely true.

## 6. Vulcan comparator

The Mercury perihelion anomaly permits a formally similar auxiliary repair:

```
known bodies adequately represented
->
additional intra-Mercurial planet may perturb Mercury
```

This is initially a low-mutilation candidate.

But the subsequent evidential trajectory fails to support the proposed planet.

That candidate can therefore move from:

`UNRESOLVED -> FAILED`

despite remaining minimally mutilating.

A deeper framework revision may then become comparatively better supported.

This is the central result:

> Minimal mutilation and empirical success are distinct dimensions.

## 7. Framework revision

A framework revision changes a larger commitment set than an auxiliary repair.

Its higher representational cost does not automatically count against it if:

- the auxiliary repair fails;
- the anomaly remains;
- the framework revision resolves the anomaly;
- the revision yields additional explanatory gain.

The audit must therefore show both preservation cost and evidential/explanatory status.

## 8. Claim-ceiling revision

Sometimes the rationally disciplined move is not yet to revise the ontology or framework.

A claim ceiling may instead contract:

> current evidence establishes an anomaly but not a uniquely correct revision target.

This is itself a legitimate revision target.

That protects FSP from manufacturing a theory choice when the evidence does not yet warrant one.

## 9. Revision frontier

REVISION-1 produces a **revision frontier** rather than a system recommendation.

The frontier reports:

- least-mutilating candidates;
- supported candidates;
- unresolved candidates;
- failed candidates.

It deliberately returns:

```
recommendation = null
```

The user, investigator, or scientific community retains authorial responsibility for judgment.

## 10. Neptune–Vulcan lesson

The Neptune and Vulcan cases have the same broad repair topology:

```
anomaly
-> retain core framework
-> revise auxiliary
-> generate new expectation
```

But the evidential outcomes differ.

Therefore no rule of the form:

```
prefer auxiliary repair because it changes less
```

is licensed.

The correct FSP representation is:

```
candidate revision
-> preservation audit
-> evidential trajectory
-> liabilities
-> explanatory gain
-> REOPEN if needed
```

## 11. Revision-choice claim ceiling

FSP may say:

- this candidate changes fewer represented commitments;
- this candidate resolves more represented anomalies;
- this candidate is currently better supported;
- this candidate introduces these liabilities;
- these revision targets remain live.

FSP may not say:

- the least mutilating revision is therefore mandatory;
- the system has found the uniquely correct belief to revise;
- successful auxiliary repair proves the retained framework true;
- failed auxiliary repair mandates immediate framework replacement;
- represented costs exhaust scientific judgment.

## 12. Relationship to Duhem and Quine

The build preserves the central Duhemian point:

> failed prediction does not uniquely identify the guilty component.

It also remains compatible with the broader Quinean possibility that revision pressure can propagate more widely through commitments.

But FSP does not adopt an unrestricted thesis that every commitment can always be retained by suitable compensation elsewhere.

The system permits:

- failed repairs;
- framework replacement;
- claim-ceiling contraction;
- task revision;
- unresolved revision frontiers.

## 13. Relationship to the frozen Translation base

REVISION-1 consumes concepts established by TRANSLATION-1 through TRANSLATION-12 but does not alter their frozen semantics.

Human-validation state remains:

- infrastructure: PASS;
- human coder evidence: PENDING.

Nothing in REVISION-1 upgrades that status.

## 14. Research ceiling

REVISION-1 establishes a governed revision space.

It does not establish a universal theory-choice algorithm.

The strongest present claim is:

> FSP can distinguish and compare multiple revision targets, make preservation cost explicit, and track why a minimally disruptive repair may succeed in one case and fail in another, while refusing to infer a uniquely rational revision solely from minimal mutilation.

## 15. Next question

The next harder problem is:

> What kinds of reasons can legitimately move a candidate upward or downward on the revision frontier when preservation, empirical fit, explanatory gain, simplicity, coherence, and social/institutional constraints conflict?

That should be addressed only after this revision grammar passes its regression gate.
