# 1. Promotion Rule

An orientation artifact may advance from CANDIDATE to SOURCE-REVIEWED only if it has:

1. a prose-first opening problem;
2. explicit canonical-owner links;
3. domain-source ledger;
4. translation-burden map;
5. claim ceiling;
6. research frontier;
7. deeper routes;
8. no duplicate canonical ownership.

SOURCE-REVIEWED does not mean PUBLIC-READY.

# 3. Source-Status Classes

Use:

**PRIMARY DOMAIN SOURCE** — original empirical, historical, or philosophical source.

**REVIEW / SYNTHESIS** — literature review, systematic review, or scholarly synthesis.

**FSP CANONICAL / RESEARCH OWNER** — internal architecture governing FSP semantics.

**ORIENTATION INFERENCE** — synthesis created by the orientation author from sources and FSP architecture.

These must remain distinguishable.

# 4. Claim-Level Source Rule

An orientation may have a bibliography, but bibliography alone is insufficient for deep public release.

Any claim involving:
- a named experiment;
- neurological causation;
- therapeutic efficacy;
- biological memory;
- synthetic-organism capability;
- VR learning effectiveness;
- a historical person's motive or transformation

must resolve to a claim-level source ledger when promoted.

# 5. Translation-Burden Audit

The four orientations collectively test these crossings:

Agency:
**cause → capacity → responsibility → institutional response**

Perception / Intelligence:
**signal → model → adaptive organization → intelligence claim → consciousness claim → standing**

Lives:
**record → biographical reconstruction → transformation interpretation → exemplar portability**

VR:
**canonical dossier → immersive representation → learner inference → personal Return**

No crossing is licensed merely by adjacency.

# 6. Orientation Grammar Regression

All four orientations must preserve:

**OPENING PROBLEM → EXISTING MAPS → TRANSLATION BURDENS → FSP CONTRIBUTION → CLAIM CEILING → RESEARCH FRONTIER → DEEPER ROUTES**

They may differ narratively.

They may not omit claim ceiling or source status.

# 7. Public Promotion Decision

None of the four orientations is yet PUBLIC-READY.

Agency, Perception/Intelligence, and VR are SOURCE-REVIEWED but still require claim-level ledger encoding.

Lives is architecture-ready but awaits Phase-3 sourced dossiers before public case routing.

# 8. Strongest Supported Claim

Their role is to make translation burdens visible, preserve domain-native evidence, expose FSP's governance contribution, and route readers toward deeper sources and unresolved research.

# 9. REOPEN

Reopen if source review reveals that:
- a domain claim is stronger than its evidence;
- a source family is outdated or contested;
- orientation synthesis obscures disagreement;
- FSP inference is presented as domain consensus;
- case-level biography is introduced without dossier sourcing.
