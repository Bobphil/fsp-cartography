# FSP-ENCYCLOPEDIA-HOME-CASE-PROGRAM-1

## Home-page reconciliation with the five-case program

This corrective pass updates the Encyclopedia home page to reflect the architecture that now actually exists.

The earlier home page was historically accurate to the first public stage, when Neptune/Vulcan was the only complete narrative/reader vertical slice. It became misleading as Galileo and Newton→Einstein acquired full whole-inquiry narrative spines.

The corrected public hierarchy is now:

```text
FSP Encyclopedia
  ↓
Why these five cases?
  ├─ Foucault — discriminating experiment / claim ceiling
  ├─ Neptune/Vulcan — divergent repair trajectories
  ├─ Galileo — evidence / meaning / standing / power
  ├─ Newton→Einstein — conceptual change / bounded continuity
  └─ DESI 2024–2026 — live revision frontier
```

Neptune/Vulcan remains the recommended first journey because it currently has the deepest interactive Atlas reader.

It is no longer presented as if it were the Encyclopedia's only substantive case.

The home page now directly exposes the three completed whole-inquiry narratives:

- Neptune/Vulcan
- Galileo
- Newton→Einstein

Foucault and DESI remain visible as deliberate members of the comparative program and are labeled honestly as Atlas cases whose full narrative spines are not yet public.

## Ongoing maintenance rule

Whenever a case crosses a public-production threshold—Atlas only → narrative spine → deep reader—the Home page and case-program overview must update in the same build or immediately following reconciliation pass.

This prevents the public shell from lagging behind the semantic/content architecture.

## Claim ceiling

This pass corrects public discoverability and project representation.

It does not yet create narrative spines for Foucault or DESI, nor deep readers for Galileo or Newton→Einstein.
