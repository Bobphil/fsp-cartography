# FSP-VR-BRIDGE-1

## Canonical Inquiry → VR Interaction Grammar

This build binds the certified VR projection profile to a concrete scene grammar.

The VR path is:

```text
canonical object
→ VR projection package
→ scene zones
→ viewpoints
→ interactions
→ temporal replay
→ scaffold fading
→ overview
→ non-immersive debrief
→ authorial return
```

The first scene is `VR-NV-VULCAN-1`.

It contains:

- Newtonian framework anchor;
- Vulcan auxiliary branch;
- observational remainder;
- historical transition reference;
- overview/return zone.

The interaction grammar includes:

- INSPECT
- MOVE_VIEWPOINT
- TOGGLE_PROBE
- REPLAY_TRANSITION
- COMPARE
- OVERVIEW
- RETURN

The first scene uses INSPECT, TOGGLE_PROBE, REPLAY_TRANSITION, COMPARE, and OVERVIEW.

Replay may alter tempo and viewpoint, never canonical sequence, provenance, or claim strength.

Viewpoints alter perceptual availability, not truth.

Scaffold fading proceeds from Guided → Reduced → Independent while retaining persistent simulation-status and return constraints.

The scene is not complete inside VR. It requires a non-immersive debrief with:

- experienced change;
- licensed inference;
- unlicensed inference;
- remaining uncertainty;
- REOPEN condition.

### Claim ceiling

This build certifies a VR interaction grammar and one scene specification. It does not establish that VR improves understanding, transfer, or judgment. Those remain research questions.
