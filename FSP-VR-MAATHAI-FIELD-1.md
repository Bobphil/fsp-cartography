# FSP-VR-MAATHAI-FIELD-1

## Non-Deployed Interactive 2D / 2.5D SVG Renderer for the Maathai-1976 Possibility Field

**Status:** EXECUTABLE VISUAL-FIELD PROTOTYPE — VERSION 1  
**Parents:** FSP-VR-VISUAL-GRAMMAR-1; FSP-VR-MAATHAI-2.0-PROJECTION-1; FSP-LIVES-IN-TRANSFORMATION-PILOT-1  
**Deployment:** NON-DEPLOYED — prototype tree only  
**Renderer:** SVG / browser DOM

# 1. Renderer Principle

The first renderer makes the possibility field visible before it asks for verbal interpretation.

The central viewing locus is Maathai circa 1976.

Paths radiate outward.

Distance from the central locus represents:

> **temporal / practical remoteness from the present state**

Nearer does not mean better, more likely, more ethical, or historically correct.

Farther does not mean impossible.

Distance indicates how much must change before that possibility can become present.

# 2. Temporal Distance Contract

Each path receives a renderer-specific temporal depth from 1 to 4.

## Depth 1 — Presently reachable

Can plausibly be attempted with capabilities/resources substantially already present.

Examples:
- investigate;
- teach / communicate;
- wait / gather evidence.

## Depth 2 — Near-term capability-building

Requires coordination, relationship activation, or modest new resources.

Examples:
- organize through women's networks;
- bounded practical experiment.

## Depth 3 — Institutionally mediated

Requires access, recognition, standing, or cooperation beyond the immediate field.

Example:
- seek institutional support.

## Depth 4 — Structurally distant

Requires multiple new conditions or authorization not presently possessed.

Example:
- broader public / political change.

> **Temporal distance ≠ probability.**

# 3. Radial Time Field

The SVG uses concentric rings around the central viewing-agent locus.

Ring 0: NOW / PRESENT FIELD  
Ring 1: reachable with present capabilities  
Ring 2: requires capability or relationship development  
Ring 3: requires institutional mediation  
Ring 4: requires substantial structural change

The rings fade toward the possibility horizon.

Later historical outcomes remain outside the visible horizon.

# 4. Gate Decomposition

A gate is not merely a locked symbol.

Selecting a gate answers:

> **What would need to become present before this path could open further?**

A gate decomposes into requirements such as:

- capability;
- resource;
- relationship;
- institutional access;
- recognized role;
- consent;
- evidence;
- authority;
- time.

Requirements may be:

- PRESENT;
- PARTIAL;
- ABSENT;
- UNKNOWN.

This makes visible that blocked or conditional action is usually structured rather than absolute.

# 5. Gate Example — State / Policy Influence

For the bounded 1976 Maathai field, public or state-directed paths may decompose into:

- scientific expertise — PRESENT;
- public communication — PRESENT / PARTIAL;
- women's organizational access — PRESENT;
- recognized state role — ABSENT;
- policy jurisdiction — ABSENT;
- institutional channel — PARTIAL / UNKNOWN;
- coalition support — PARTIAL;
- political authorization — ABSENT.

This is not a prediction of what Maathai later did.

It is a visual decomposition of capability versus authorization at a bounded historical moment.

# 6. 2.5D Convention

The renderer remains two-dimensional SVG but simulates depth through:

- radial distance;
- scale;
- opacity;
- layering;
- slight perspective offset;
- horizon rings.

Depth is semantic before aesthetic.

# 7. Interaction Contract

The learner may:

- select a locus;
- select a possibility path;
- inspect what the path requires;
- inspect a gate;
- toggle provenance;
- inspect remainder;
- change scaffold level;
- compare paths;
- reset the field.

The renderer must not identify a best path, reveal the historical outcome, infer motive, or simulate inner speech.

# 8. Path Panel

Selecting a path shows:

- action family;
- path state;
- temporal depth;
- what is already present;
- what is still required;
- affected parties;
- reversibility;
- authorization gate if present;
- provenance / claim ceiling.

# 9. Provenance Toggle

The provenance overlay distinguishes:

- historical source-supported elements;
- later-memory-supported elements;
- FSP inference;
- navigational reconstruction.

Turning the overlay off does not erase the underlying provenance.

# 10. Remainder Layer

Initial Maathai remainder markers:

- private motive unavailable;
- gender / political context requires enrichment;
- later political meaning not yet available.

# 11. Scaffold Fading

Level 3: labels, path-family explanations, temporal rings, gate requirements, provenance cues, remainder markers.  
Level 2: labels, paths, rings, gates, optional provenance.  
Level 1: loci, paths, gates, constraints, horizon.  
Level 0: Return prompts only.

# 12. Anti-Singularity Test

Before historical reveal:

- all seven path families remain inspectable;
- no path is visually designated correct;
- multiple temporal depths remain visible;
- waiting / gathering evidence remains a path;
- institutional paths decompose through gates;
- the future outcome remains outside the horizon.

# 13. First Empirical Questions

1. Does the learner interpret greater distance as “more must change first” rather than “less good”?
2. Can the learner distinguish temporal remoteness from historical likelihood?
3. Can the learner explain why a gate is present?
4. Can the learner identify one requirement already present and one absent?
5. Can the learner compare two paths without treating one as the answer?
6. Can the learner identify an unknown or incompletely sourced part of the field?
7. Can the learner describe what would have to change for a distant path to move inward?

# 14. Historical Enrichment Boundary

The following still require source enrichment before public historical release:

- childhood / land experience;
- transnational educational assembly history;
- marriage / political proximity;
- gendered academic and social constraints;
- post-independence Kenyan institutional context.

The renderer must expose these gaps rather than invent them.

# 15. Constitutional Decision

**PASS — BUILD AS NON-DEPLOYED SVG / 2.5D TEST FIELD.**

The renderer is a projection of the typed visual scene graph and does not own historical semantics.
