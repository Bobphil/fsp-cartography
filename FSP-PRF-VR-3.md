# FSP-PRF-VR-3

## Heterogeneous Sensory Worlds, Umwelt Constraint Simulation, Phenomenal-Remainder Debrief, Multi-Agent Joint Inquiry, Virtual-to-Physical Experiment Design, and Pattern-of-Discovery Transfer Test

**Status:** EXPERIMENTAL VR RESEARCH ARCHITECTURE — VERSION 3  
**Role:** Integrate FSP heterogeneous intelligence, objective phenomenology, transformation architecture, PRF governance, and scaffold-fading pedagogy into a controlled virtual-reality research environment.  
**Primary purpose:** Use VR not as a machine for simulating another organism's consciousness, but as a governed environment for varying sensory access, comparing agent-relative actionable worlds, testing cross-perspectival translation, generating physical experiments, and measuring whether training changes later salience and discrimination.  
**Primary claim ceiling:** PRF-VR-3 can simulate access architectures, task affordances, and evidence constraints. It cannot establish what another organism's experience intrinsically feels like, cannot substitute simulated success for physical validation, and cannot infer durable perceptual learning from immediate in-session performance alone.

---

# 1. Why PRF-VR-3

Earlier PRF-VR work treated VR primarily as a way to expose:

- map / world / person non-identity;
- situated perspective;
- temporal replay;
- scaffold fading;
- boundedness;
- cognitive decompression;
- debrief;
- Return to lived Doing.

The newer FSP architecture adds:

- heterogeneous sensory access;
- evidence topology;
- partial translation;
- Umwelt Constraint Maps;
- Phenomenal Translation Remainder;
- virtual-to-physical experiment loops;
- Joint Inquiry Space;
- Pattern of Discovery (RF-01);
- transformation of accessible possibility sets.

PRF-VR-3 unifies these.

The core shift is:

```text
FROM:
simulate another perspective
→ reflect on perspective limits

TO:
model access architecture
→ vary detectable structure
→ vary discriminable/actionable structure
→ compare heterogeneous agents
→ track translation remainder
→ generate experiments
→ test transfer after scaffold removal
```

# 3. Governing Distinction

The architecture must preserve:

> **Shared environment ≠ shared Umwelt.**

and:

> **Shared environment ≠ shared actionable world.**

Different agents may inhabit the same simulated environment while receiving different access to it.

# 4. World Model

Define:

```text
W_VR
```

as the virtual environment model.

It may contain:

- geometry;
- objects;
- motion;
- signal sources;
- hidden state;
- temporal dynamics;
- ecological relations;
- hazards;
- resources;
- social agents.

The world model is not directly presented to every participant.

> **World model ≠ rendered experience.**

---

# 5. Sensory Profile

Define:

```text
SensoryProfile_i = {
  modalities,
  bandwidth,
  thresholds,
  range,
  spatialResolution,
  temporalResolution,
  latency,
  noise,
  activeSensingRules,
  integrationRules,
  adaptationRules,
  maskingRules,
  claimCeiling
}
```

Examples:

- ordinary human visual/auditory;
- bat-like echo access;
- polarization-sensitive;
- chemical-gradient;
- electroreceptive;
- infrared-sensitive;
- instrument-augmented;
- AI feature access.

A sensory profile is a simulation parameterization.

> **Sensory profile ≠ organism.**

---

# 6. Detectable Structure

For agent (i):

```text
D_i(W_VR)
```

is the portion of virtual-world structure detectable under its sensory profile.

This can be manipulated experimentally through:

- range;
- noise;
- timing;
- occlusion;
- sensor loss;
- multimodal access;
- active-sensing cost.

> **Present in world ≠ detectable by agent.**

---

# 7. Discriminable Structure

Detection does not guarantee discrimination.

Define:

```text
Q_i(D_i(W_VR))
```

as distinctions the agent can reliably make.

A signal may be physically available but behaviorally unusable.

> **Detectable ≠ discriminable.**

---

# 8. Actionable Structure

Define:

```text
A_i(Q_i(D_i(W_VR)))
```

as relations that can guide action.

Examples:

- obstacle location;
- target distance;
- safe route;
- prey direction;
- conspecific identity;
- resource gradient.

> **Discriminable ≠ actionable.**

---

# 9. Phenomenal Ceiling

For human VR users, the system can record subjective reports.

For nonhuman modeled agents, the system cannot infer phenomenal identity from task success.

Therefore:

> **Actionable structure ≠ phenomenal character.**

> **VR rendering ≠ another organism's experience.**

The interface should make this claim ceiling visible during and after a session.

# 15. Translation Edges

A translation from agent (i) to human representation (H) may be written:

```text
τ_iH
```

The system should record:

- preserved information;
- transformed information;
- unavailable information;
- added visualization conventions;
- inferred relations.

Thus:

> **Translation aid ≠ perceptual equivalence.**

---

# 16. Translation-Remainder Display

Every cross-perspectival VR mode should expose:

```text
TRANSLATED
what the interface successfully renders

INFERRED
what follows from performance or model structure

NOT TRANSLATED
what the simulation cannot carry over

UNKNOWN
what remains empirically unresolved
```

This is the VR form of the Phenomenal Translation Remainder.

---

# 17. Phenomenal-Remainder Debrief

At session end, the system should require a bounded debrief:

```text
1. What became accessible?
2. What became actionable?
3. What did the simulation make easier to imagine?
4. What did you infer?
5. Which inference was not directly supported?
6. What remained untranslated?
7. What did the interface tempt you to anthropomorphize?
8. What new experiment would distinguish remaining possibilities?
9. What claim ceiling should remain?
10. What do you carry back into lived Doing?
```

The debrief is not an optional reflection layer.

It is part of the research architecture.

---

# 18. Overreach Sentinel

The VR system should flag claims such as:

- “This is what bats see.”
- “This is what echolocation feels like.”
- “The AI perceives the world this way.”
- “The organism must experience distance as…”
- “The simulation proves…”

These should trigger:

> **REPRESENTATION / PHENOMENOLOGY OVERREACH**

and route to the remainder panel.

# 23. Temporal Replay

PRF-VR-3 preserves temporal replay.

A participant should be able to inspect:

```text
signal
→ detection
→ discrimination
→ action
→ consequence
```

and replay moments where:

- relevant information was available but unnoticed;
- a translation changed interpretation;
- a different sensor profile changed action;
- uncertainty increased.

Replay supports assembly-history inspection.

---

# 24. Counterfactual Replay

The same event can be rerun under alternative access conditions:

```text
same W_VR
+
different SensoryProfile
→
different accessible structure
```

This is a direct demonstration of:

> **Same environment ≠ same accessible world.**

---

# 25. Transformation of Accessible Possibility

PRF-VR-3 should connect sensory access to Transformation Architecture.

Let:

```text
F_i(W)
```

be feasible transformations.

Let:

```text
A_i(W) ⊆ F_i(W)
```

be transformations visible or salient to the agent.

Training may alter:

```text
A_i(W)_pre → A_i(W)_post
```

even when the environment is unchanged.

This is the core empirical bridge to Pattern of Discovery (RF-01).

---

# 26. Pattern-of-Discovery Transfer Test

The key research question:

> **Does repeated PRF-VR training change what participants spontaneously notice and discriminate after explicit scaffolds are removed?**

The protocol should separate:

```text
in-session performance
≠
near transfer
≠
far transfer
≠
durable transfer
```

---

# 27. Transfer-Test Sequence

A minimal design is:

```text
PRETEST
↓
guided VR training
↓
repeated practice
↓
scaffold fading
↓
novel VR case
↓
non-VR or differently rendered case
↓
delayed retest
```

Measures may include:

- spontaneous discrimination;
- attention allocation;
- unprompted use of relevant distinctions;
- error detection;
- claim-ceiling use;
- overreach avoidance;
- hypothesis generation.

---

# 28. Scaffold Fading

The training sequence should remove supports gradually.

Example:

```text
Stage 1:
explicit labels

Stage 2:
labels on request

Stage 3:
visual cues only

Stage 4:
no cues

Stage 5:
novel environment
```

The purpose is to test whether structure has become perceptually or cognitively available without the vocabulary prompt.

> **Tool recall ≠ transformed discrimination.**

---

# 29. Transfer Claim Ceiling

A successful immediate posttest permits:

> participant performance improved under nearby conditions.

It does not yet permit:

> FSP has transformed perception.

That stronger claim requires:

- novel cases;
- scaffold-free performance;
- delayed retention;
- replication.

# 36. Error as Research Signal

A failed VR agent should not simply receive a lower score.

Its failure may reveal:

- insufficient access;
- bad translation;
- hidden latency;
- incorrect world model;
- missing variable;
- inappropriate task assumption.

Thus:

> **Performance failure ≠ useless data.**

This supports diagnostic research.

---

# 37. Anthropomorphism Sentinel

The system should track when users infer:

- intention from adaptive behavior;
- consciousness from competence;
- human-like salience from task success;
- human categories from alien sensing.

Debrief prompt:

> **What did the agent do, and what did you add?**

This is a VR application of Map ≠ World ≠ Person.

---

# 38. Mechanomorphism Sentinel

The reverse error must also be tracked.

Users may assume:

- biological systems are merely machines;
- computational description exhausts biological organization;
- measured variables exhaust lived significance.

Thus:

> **Avoiding anthropomorphism ≠ reducing organism to mechanism.**

PRF-VR-3 should pressure both errors.

---

# 39. Accessibility and Human Factors

Because VR can create disorientation, the architecture should permit:

- seated mode;
- reduced-motion mode;
- adjustable intensity;
- pause / exit;
- non-VR desktop parity;
- clear sensory-transition warnings;
- decompression phase.

A research result should not depend on preventable discomfort.

---

# 40. Cognitive Decompression

After a strong sensory transformation, the participant should return gradually.

Sequence:

```text
altered access
↓
neutral environment
↓
ordinary access restoration
↓
remainder debrief
↓
Return
```

This preserves the existing FSP-VR decompression principle.

---

# 41. Authorial Return

The final stage asks:

- What changed in what you notice?
- What did not change?
- Which inference should you now distrust?
- What new question became visible?
- Where would this distinction matter outside VR?

Return is not:

> “What lesson did the simulation teach?”

It is:

> **What will you now do differently, and under what claim ceiling?**

# 42. Research Modes

PRF-VR-3 supports four principal modes.

## Mode A — Perspective Reconstruction

Compare access architectures within one environment.

## Mode B — Objective Phenomenology

Build Umwelt Constraint Maps while preserving phenomenal remainder.

## Mode C — Heterogeneous Joint Inquiry

Coordinate human, computational, and instrument-like agents.

## Mode D — Transformation Training

Test whether scaffold fading changes later salience and discrimination.

The modes can share infrastructure without sharing claims.

# 52. Regression Invariants

PRF-VR-3 passes only if:

**R1 — Map/world/person preserved:** VR never becomes world or person.

**R2 — Umwelt preserved:** shared environment does not imply shared world.

**R3 — Phenomenal ceiling preserved:** no simulated sensory mapping is presented as first-person equivalence.

**R4 — Heterogeneous agents preserved:** human, biological, computational, and instrumental roles remain distinct.

**R5 — Translation remainder preserved:** interface makes loss explicit.

**R6 — Active sensing preserved:** action can alter evidence acquisition.

**R7 — Joint Inquiry / JTS separation preserved:** inquiry does not equal authorization.

**R8 — Virtual / physical distinction preserved:** simulated evidence does not establish physical claims.

**R9 — RF-01 preserved:** Pattern of Discovery remains an empirical Frontier.

**R10 — Transfer discipline preserved:** vocabulary or immediate performance does not count as durable perceptual transformation.

**R11 — Anti-anthropomorphism preserved.**

**R12 — Anti-mechanomorphism preserved.**

**R13 — Data-layer separation preserved:** simulation, behavior, report, inference, interpretation remain typed.

**R14 — Return preserved:** session ends in bounded lived Doing, not model closure.

# 61. Claim Ceiling

PRF-VR-3 does not establish:

- what it is intrinsically like to be a bat or any nonhuman organism;
- that VR can reproduce another organism's phenomenology;
- that artificial agents possess experience;
- that virtual performance establishes biological mechanism;
- that immediate learning equals durable perceptual transformation;
- that cross-perspectival simulation resolves first-/third-person evidence;
- that Joint Inquiry creates a collective mind;
- that one VR formalism applies to every sensory ecology;
- that VR-generated experiment proposals are automatically ethical, safe, or scientifically warranted.

---

# 62. REOPEN Conditions

Reopen if:

- users consistently confuse sensory rendering with phenomenology;
- translation remainder cannot be made usable;
- agent comparisons encourage scalar intelligence ranking;
- scaffold fading fails to produce measurable transfer;
- VR sickness or accessibility issues distort results;
- artificial sensory agents fail to generate useful experimental discriminations;
- real-world tests repeatedly contradict the virtual model;
- objective-phenomenology cases require incompatible sensory architecture;
- RF-01 or RF-02 develops a stronger formalism.

---

# 63. Final Statement

PRF-VR-3 should not ask:

> **Can VR make us experience what it is like to be another organism?**

It should ask:

> **Can VR let us rigorously vary access to a shared environment, discover how different sensory architectures change what becomes detectable and actionable, expose the limits of translation, generate better hypotheses, design discriminating experiments, and train humans to notice those distinctions after the scaffolds are gone?**

Its governing loop is:

```text
shared world
→ heterogeneous access
→ different actionable worlds
→ comparison
→ remainder
→ hypothesis
→ experiment
→ revised map
→ scaffold fading
→ transfer test
→ Return
```

And its deepest firewall is:

> **A more powerful simulation of another perspective is still a map, not possession of that perspective.**
