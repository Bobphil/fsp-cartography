# Frozen CODE-0 Specification

Prototype 0 is a single-user, local-first, task-bounded cartography kernel.

Frozen distinctions:

- Map != World
- My Map of Other != Other
- Inference != Report
- Institution != Person
- Power != Authority
- Shared Task != Required Agreement
- Possibility != Prediction
- System Candidate != User Judgment
- Private != Course
- REOPEN != Permanent Openness

Required behavior:

1. A task may be FORMED or UNFORMED.
2. Another person is represented as MY_MAP_OF_OTHER.
3. Claims preserve SELF_REPORT / OTHER_REPORT / OBSERVATION / USER_INFERENCE / SOURCE_DERIVED / UNKNOWN.
4. Institutions are typed separately from people.
5. Constraints have independent epistemic status and practical rigidity.
6. Shared task may be NONE_IDENTIFIED.
7. Power and authority remain distinct connection types.
8. Rejected deterministic Coach interpretations remain suppressed until explicitly reopened.
9. PRIVATE -> COURSE creates a projection; it never mutates the private original.
10. Authorial Return permits JUDGMENT / INVESTIGATE / NARROW / CONFIRM_CONSTRAINT / REJECT_INTERPRETATION / UNRESOLVED / SUSPEND.
