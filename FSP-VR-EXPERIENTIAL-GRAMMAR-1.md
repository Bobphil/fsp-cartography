# FSP-VR-EXPERIENTIAL-GRAMMAR-1

## Cross-Domain Experiential Operations, Multisensory Iconography, Temporal Decompression, Oracle Governance, and Semantic-Stability Contract

**Status:** CROSS-CUTTING DESIGN CONSTITUTION — REVISION 1  
**Scope:** FSP-VR and any future FSP interface that uses visual, auditory, spatial, temporal, haptic, interactive, or immersive cues.  
**Purpose:** preserve a reusable experiential language so FSP distinctions are encountered through stable operations rather than merely named in prose.

# 1. Governing Architectural Principle

> **Every major FSP distinction should eventually have an experiential operation, not merely a label.**

A distinction is not fully implemented in FSP-VR merely because its name, definition, or icon appears on screen.

For each major distinction, the learner should be able to encounter some combination of:

- a perceptual cue;
- a spatial relation;
- a temporal behavior;
- an action;
- a resistance;
- a transition;
- a comparison;
- a source;
- a boundary;
- a remainder;
- a return.

A second rule follows:

> **If the learner could acquire the distinction equally well from a paragraph beside a static diagram, the immersive implementation has not yet justified itself.**

# 2. Why Immersion Matters

FSP-VR should exploit the dimensions of ordinary lived experience that linear prose serializes:

- spatial coexistence;
- embodied action;
- temporal flow;
- orientation and viewpoint;
- auditory localization;
- tactile feedback;
- salience;
- memory traces;
- anticipation;
- emotional response;
- changing capability;
- changing relation;
- present-relative inquiry.

The purpose is not spectacle.

The purpose is to let the learner temporarily **decompress structures that ordinary human cognition must normally compress**.

# 3. Core Experiential Loop

The preferred inquiry loop is:

**LIVE → NOTICE → ACT → EXPERIENCE CONSEQUENCE → FREEZE → DECOMPRESS → INSPECT → COMPARE → RECONSTRUCT → EXPLORE POSSIBILITY → RETURN → ACT AGAIN**

This loop should recur across domains.

# 4. Temporal Operations

## FREEZE

Experience:
- motion pauses;
- sound thins or stretches;
- nearby relations separate;
- hidden detail becomes inspectable.

Meaning:
> create extra epistemic time.

Freeze is not merely pause.

It must increase inspectability.

## SLOW

Experience:
- transitions proceed stepwise;
- causal / relational changes become discriminable.

Meaning:
> inspect how a state becomes another state.

## ACCELERATE

Experience:
- local detail compresses;
- farther consequences, dependencies, and possibilities become visible.

Meaning:
> widen temporal reach without converting future into prediction.

## RETURN

Experience:
- decompressed relations recombine;
- ordinary experiential scale resumes;
- altered knowledge/capability remains available.

Meaning:
> inquiry returns to lived Doing.

# 5. Stable Experiential Signatures

The following FSP elements should acquire stable multisensory signatures across domains.

## Doing
- visual: event/action/change;
- interaction: learner initiates movement or response;
- haptic: light confirmation of successful action;
- meaning: something is happening and agency is possible.

## Situated Perspective
- visual: partial field from current position;
- auditory: sounds may originate outside current view;
- interaction: turn, move, relocate;
- meaning: access depends on standpoint.

## Salience
- visual/auditory emphasis draws attention;
- interaction: learner may redirect attention;
- meaning: salience affects access but does not determine truth.

## Capability
- visual: paths/actions become newly available;
- interaction: previously unavailable action can now be performed;
- meaning: capability alters the possibility field.

## Constraint
- visual: boundary or blocked path;
- interaction: resistance, failed action, rerouting;
- haptic: resistance or distinct failure cue;
- meaning: some actions are presently limited.

## Other Agent
- visual: independent trajectory;
- auditory: autonomous timing;
- interaction: signal/coordinate but cannot command;
- meaning: MY DOING ≠ OTHER DOING.

## Connected Doing
- visual: one agent's action changes another's possibilities;
- interaction: coordinate, assist, obstruct, wait;
- meaning: action is relational and mutually consequential.

## Dependency
- visual: needed resource/response lies partly outside learner control;
- interaction: signal/request/wait;
- meaning: agency can coexist with dependence.

## Influence ≠ Control
- visual: response probabilities vary;
- interaction: same signal can succeed or fail;
- meaning: affecting a system is not commanding it.

## Regularity
- visual: repeated temporal traces;
- auditory: recurring pattern;
- meaning: expectations arise from recurring structure.

## Regularity ≠ Necessity
- visual: familiar sequence fails;
- interaction: Freeze and compare prior traces;
- meaning: past regularity does not guarantee continuation.

## REOPEN
- visual: previously compressed/settled object expands;
- interaction: reopen, revise, inspect;
- meaning: inquiry resumes when pressure or failure warrants it.

## Past Trace
- visual: lower-salience trace behind current state;
- interaction: inspect but not alter;
- meaning: past remains evidentially relevant without becoming present.

## Present / NOW
- visual: highest-resolution interactive field;
- meaning: inquiry is always performed from a current situated state.

## Possible Future
- visual: farther / semi-transparent / conditional structure;
- interaction: inspect prerequisites;
- meaning: possible ≠ actual.

## Possibility Horizon
- visual: distant retained band/edge;
- interaction: pin/re-enter;
- meaning: distant possibility remains available without becoming nearer.

## Path
- visual: route with checkpoints;
- interaction: follow, compare, abandon;
- meaning: possibilities have prerequisites and structure.

## Gate
- visual: threshold interrupts a path;
- interaction: inspect requirements, request access, change role;
- meaning: reachability can depend on prerequisites.

## Authorization
- visual: gate tied to role/consent/jurisdiction;
- interaction: request, obtain consent, refrain;
- meaning: CAPABILITY ≠ AUTHORIZATION.

## Contingency Chain
- visual: status checkpoints along path;
- interaction: inspect PRESENT / PARTIAL / ABSENT / UNKNOWN;
- meaning: future reachability depends on conditions.

## Probability / Risk
- visual: field/cloud/distribution, not path;
- interaction: inspect range/uncertainty;
- meaning: risk ≠ fate.

## Distribution
- visual: range/density rather than single value;
- interaction: inspect subgroup/source;
- meaning: population statistic ≠ individual destiny.

## Outcome
- visual: completed state distinct from earlier possibility;
- meaning: outcome ≠ prior probability; hindsight ≠ foresight.

## Evidence
- visual: inspectable source object;
- interaction: open, compare, group;
- meaning: claims depend on particular evidence.

## Observation
- visual: record layer distinct from interpretation;
- meaning: observation ≠ interpretation.

## Interpretation
- visual: detachable explanatory layer;
- interaction: toggle competing interpretations;
- meaning: evidence requires inference.

## Alternative Explanation
- visual: adjacent competing map;
- interaction: compare/test;
- meaning: one explanation does not erase alternatives.

## Replication
- visual: later study aligned with original;
- interaction: compare design/results;
- meaning: initial result ≠ settled knowledge.

## Source Ledger / Provenance
- visual: source/date/method/provenance object;
- interaction: drill down;
- meaning: information has an assembly history.

## Claim Ceiling
- visual: boundary beyond which inference cannot propagate cleanly;
- interaction: attempt extension and encounter limit;
- meaning: evidence licenses only so much.

## Remainder / Unknown
- visual: explicit open edge / unresolved region;
- auditory: silence may be meaningful;
- interaction: leave unresolved;
- meaning: unknown ≠ hidden answer.

## Map ≠ World
- visual: maps as removable overlays;
- interaction: toggle/compare maps while world persists;
- meaning: representation ≠ represented.

## Map Revision
- visual: old/new maps overlaid or side-by-side;
- interaction: compare changed assumptions;
- meaning: inquiry changes maps through time.

## Assembly History
- visual: current capability traces backward through contributing relations/events;
- interaction: follow formation history;
- meaning: present states have histories.

## Transition
- visual: state changes while altered relations remain visible;
- interaction: step before/after;
- meaning: change concerns relation structure, not merely snapshots.

## Re-location
- visual: learner/agent occupies a changed field after action;
- meaning: action changes the standpoint of subsequent inquiry.

## Institutional Field
- visual: compressed institution can expand into roles/rules/resources/authority/people;
- interaction: enter/decompress/inspect;
- meaning: institution ≠ single actor.

## Role
- visual: access/affordance changes with role;
- interaction: inspect same institution from another role;
- meaning: role changes access without changing whole world.

## Power
- visual: some loci alter others' paths/resources/gates;
- interaction: trace effects;
- meaning: practical power is visible through effects.

## Authority
- visual: recognized formal channels/gates;
- interaction: invoke/challenge/appeal;
- meaning: authority ≠ practical power.

## Culture
- visual: overlapping heterogeneous fields;
- auditory: polyphonic voices rather than one culture voice;
- interaction: inspect layers;
- meaning: culture is recursive and heterogeneous.

## Norm
- visual: repeated social expectations/responses;
- interaction: conform/violate/inspect consequence;
- meaning: norms can precede explicit justification.

## Social Approval ≠ Moral Justification
- visual: approval cue remains separate from reason/justification layer;
- meaning: group response does not settle moral status.

## Preference ≠ Reason
- visual: preference recorded while explanation remains open;
- interaction: choose, then inquire;
- meaning: choice does not automatically supply justification.

## Emotion / Salience
- visual/auditory/haptic field may intensify while evidence remains unchanged;
- interaction: Freeze emotional moment;
- meaning: salience ≠ truth.

## Person ≠ Dossier
- visual: data layers surround but do not replace person locus;
- interaction: hide/show layers;
- meaning: person exceeds every representation.

## Self-Report ≠ Inference
- visual: distinct provenance textures;
- interaction: accept/reject/correct inference;
- meaning: system does not author identity for user.

## Authorial Capability
- visual: learner can alter map, projects, routes;
- interaction: revise/authorize/defer/reopen;
- meaning: user participates in their own map construction.

## Counterfactual Probe
- visual: alternate field adjacent to current one;
- interaction: change controlled variables;
- meaning: WHAT IF is governed inquiry.

## Analogy
- visual: aligned structural correspondence with preserved differences;
- interaction: compare relations;
- meaning: structural similarity ≠ identity.

## Scale Change
- visual: body → family → institution → society → system;
- interaction: zoom in/out while preserving links;
- meaning: explanation changes with scale.

## System Dependency
- visual: networks with cascading effects;
- interaction: interrupt node and inspect propagation;
- meaning: local action can have system consequences.

## Failure Routing
- visual: failed path highlights affected assumption/source/gate;
- interaction: follow failure backward;
- meaning: failure should reopen relevant structure, not collapse entire inquiry.

## Consequential Return
- visual: return to present with changed paths/knowledge visible;
- interaction: choose next action;
- meaning: inquiry must matter for subsequent Doing.

## OFF
- visual: overlays and interface recede;
- interaction: exit/stop;
- meaning: cognitive prosthesis must remain relinquishable.

# 6. Experiential Operation Families

Prefer reuse of a small number of interaction families rather than creating one-off mechanics.

- **Freeze / Expand** → decompression
- **Slow / Step** → transition inspection
- **Accelerate / Zoom Out** → long-range dependency / possibility
- **Turn / Relocate** → situated perspective
- **Reach / Act** → capability test
- **Encounter Resistance** → constraint
- **Signal / Wait** → dependency and limited influence
- **Open / Drill Down** → source and internal structure
- **Pin** → retain in working attention
- **Place Side by Side** → comparison
- **Trace Backward** → assembly history
- **Trace Forward** → consequence / contingency
- **Cross Gate** → authorization / prerequisite
- **Hit Boundary** → claim ceiling
- **Leave Open Edge** → remainder
- **Overlay Maps** → representation/world separation
- **Recompose / Return** → actionable judgment
- **Turn OFF** → boundedness / autonomy

# 7. Multisensory Iconography Contract

FSP-VR may use:

- shape;
- color/value;
- opacity;
- texture;
- spatial placement;
- motion;
- animation timing;
- sound motif;
- spatial audio;
- haptic pattern;
- interaction response;
- temporal behavior.

But semantic stability is mandatory.

> **A recurring FSP concept should have a stable experiential signature, and a recurring experiential signature should preserve its meaning wherever it appears.**

Local modules may vary theme, aesthetics, soundscape, and narrative identity.

The underlying FSP grammar should remain recognizable.

# 8. Domain Portability

The same grammar should travel across:

- developmental entry;
- life lottery;
- actual-life reconstruction;
- historical Lives;
- ethics;
- philosophy of science;
- medicine;
- institutions;
- political systems;
- economic systems;
- culture;
- consciousness;
- AI;
- existential risk;
- sentience;
- future special-topic FSP domains.

Example:

A gate should still mean prerequisite/authorization whether it appears in:
- infancy;
- schooling;
- healthcare;
- Maathai's institutional world;
- scientific publication;
- AI governance.

An unknown should remain genuinely unresolved everywhere.

# 9. Oracle / Fourth-Wall Interjection

FSP-VR may use a recurring meta-level guide/oracle as a transitional and inquiry device.

The oracle is explicitly outside the simulated object-level world.

## Allowed functions

- narrative compression across long spans;
- scene transition;
- rapid world-data retrieval;
- source retrieval;
- provenance display;
- reminder of previously learned structures;
- metacognitive prompts;
- inquiry-route suggestions;
- comparison setup;
- temporal jump;
- explanation of interface grammar.

## Forbidden functions

The oracle must not become:
- omniscient narrator;
- moral authority;
- hidden truth source;
- substitute for exploration;
- speaker for another person's private experience;
- automatic recommender;
- final authorizer.

## Governing distinction

> **Oracle = navigation + compression + evidence retrieval + metacognitive prompting**
>
> **Oracle ≠ truth oracle**

The oracle itself must remain source-bounded and capable of saying:

> We do not know.

It should eventually be possible for the oracle to remind the learner:

> **I am also a map.**

# 10. Fourth-Wall Transition Signature

When oracle/meta-level mode activates:

- object-level scene remains faintly visible;
- time may pause;
- sensory saturation may reduce;
- a distinct sound motif signals meta-level;
- learner retains orientation to where they came from.

This prevents the meta-layer from masquerading as the world itself.

# 11. Experiential-Operation Regression Test

For every major FSP distinction used in a scene, answer:

1. **What does the learner perceive?**
2. **What can the learner do?**
3. **What changes when they do it?**
4. **Which sensory cue carries the distinction?**
5. **How can they inspect it more deeply?**
6. **How would misunderstanding be detected?**
7. **How do they return to ordinary Doing?**

If these cannot be answered, the feature is probably still content placed inside VR rather than an immersive FSP operation.

# 12. Semantic-Stability Regression

For any reused cue, ask:

- Does this cue mean the same thing in every domain?
- If not, is the variation explicitly signaled?
- Could a learner reasonably transfer the wrong meaning from a previous scene?
- Has decorative styling accidentally acquired semantic force?
- Can the cue survive scaffold fading?

# 13. Compression / Decompression Regression

For every major compressed object, ask:

- What has ordinary cognition compressed here?
- Can the user decompress it?
- Does decompression reveal relations rather than merely more prose?
- Can the learner compare decompressed components simultaneously?
- Can the learner responsibly recompose the object?
- Does Return preserve what matters without requiring maximal complexity?

# 14. Telecourse Continuity Principle

FSP-VR extends a pedagogical design principle previously used in educational telecourse/video production:

- recurring graphic identity;
- recurring musical/audio motifs;
- topic-specific cues;
- cross-media continuity;
- recognizable domain signatures.

The VR extension is that the iconography becomes **operational**.

A symbol is not merely recognized.

It can be:
- opened;
- resisted;
- crossed;
- traced;
- compared;
- frozen;
- replayed;
- pinned;
- decompressed;
- returned from.

Thus:

> **mnemonic iconography → interactive epistemic grammar**

# 15. Revision Policy

This grammar is intentionally revisable.

Future evidence or usability testing may require:
- changing a cue;
- splitting a distinction;
- merging redundant operations;
- demoting a cue to domain-local use;
- creating a new operation where no existing one works.

Apply the anti-proliferation sequence:

**REUSE → DECOMPRESS → SUBTYPE → DOMAIN-LOCAL → FRONTIER → only then ADD**

# 17. Cooperation Without Convergence / FIND OVERLAP

FSP-VR adopts **FIND OVERLAP** as a reusable experiential operation.

Experience:
- two or more agents retain visibly distinct normative / evaluative fields;
- separate reason paths remain attached to each agent;
- a shared action corridor appears only where their independently authorized actions overlap;
- proposed changes can widen, narrow, or eliminate that corridor;
- disagreement remains visible after coordination.

Learner operations:
- select agents / maps;
- expose relevant authorization sets;
- inspect constraints and prohibitions;
- invoke **FIND OVERLAP**;
- modify scope, procedure, governance, consent, timing, distribution, reversibility, or oversight;
- inspect whether overlap changes;
- authorize only the bounded shared task;
- Return with unresolved disagreement preserved.

Stable firewalls:

> **OVERLAP ≠ CONVERGENCE**
>
> **COOPERATION ≠ ENDORSEMENT**
>
> **TASK-LOCAL AGREEMENT ≠ WORLDVIEW AGREEMENT**

Visual rule:

> **Do not use a merge animation that implies worldview unification.**

The common corridor should be shown as a bounded practical overlap inside non-identical normative worlds.

Regression question:

> **What can these agents responsibly do together now without pretending that they agree about everything else?**
