# FSP and the Duhem–Quine Problem

## Purpose

This note applies the current FSP-TRANSLATION results to canonical Duhemian and Quinean problem structures.

The aim is not to claim that FSP solves underdetermination.

The narrower question is:

> Which parts of the Duhem–Quine problem can FSP represent explicitly, which parts can it test, and which parts remain genuinely unresolved?

## 1. Duhem's holism

Duhem's central point is that an experimental prediction is not derived from one hypothesis alone.

It depends on a group including:

- target hypothesis;
- auxiliary hypotheses;
- background theory;
- instrument assumptions;
- measurement assumptions;
- initial and boundary conditions;
- inferential links between theory and observation.

Therefore failed prediction implies only that something in the tested conjunction requires revision.

The experiment does not by itself identify which component.

### FSP mapping

FSP represents this structure through:

- claim;
- evidence;
- warrant;
- background commitments;
- auxiliary assumptions;
- task;
- claim ceiling;
- REOPEN.

TRANSLATION-3 added time-indexed auxiliary perturbation.

TRANSLATION-4 added auxiliary sensitivity and ablation.

This means FSP can represent:

```
prediction failure
-> multiple possible revision targets
-> auxiliary perturbation
-> recompute task-relevant signature
-> preserve / reopen / break
```

FSP does not infer a uniquely correct revision target.

That limitation matches the Duhemian problem rather than solving it away.

## 2. Foucault and wave-versus-particle light

Duhem's famous optics example concerns the attempt to treat Foucault's measurement of light speed in air and water as a crucial experiment between wave and emission theories.

The historical lesson is not merely that one prediction won.

The theoretical consequence depended on a wider structure of assumptions and theory.

### FSP result

FSP would encode at least two PRFs or theory-framework records:

- wave framework;
- emission framework.

Each would include:

- target theoretical commitment;
- auxiliary optical assumptions;
- instrument/measurement assumptions;
- predicted speed relation;
- claim ceiling.

The experimental result becomes a perturbation.

If the wave and emission task signatures diverge after that observation, FSP reports:

`BROKEN_BY_TASK_RELEVANT_DIFFERENCE`

But this does not license:

`ONTOLOGICAL_UNIQUENESS`

because the experiment can discriminate represented prediction structures without proving that every possible auxiliary reconstruction of the rival framework is impossible.

FSP therefore reproduces Duhem's rejection of a logically final experimentum crucis.

## 3. Uranus and Neptune

Newtonian celestial mechanics failed to predict Uranus's orbit correctly.

Scientists retained Newtonian dynamics and revised an auxiliary assumption concerning the contents of the solar system.

The additional-planet hypothesis led to Neptune.

### FSP result

This is a paradigmatic:

`REOPEN_AUXILIARIES`

case.

The target theory is provisionally held fixed.

A background assumption changes:

```
known gravitating bodies
->
additional unseen planet possible
```

The altered auxiliary network generates a new prediction.

The subsequent discovery of Neptune increases support for that repaired task-level structure.

FSP can represent:

- which assumption changed;
- which predictions changed;
- why the repair was licensed;
- what evidence later supported it;
- which parts of the original framework remained unchanged.

FSP does not infer from Neptune's success that Newtonian ontology is uniquely true.

Successful repair does not authorize ontological promotion.

## 4. Mercury and Vulcan

A similar strategy was used for Mercury's anomalous perihelion.

An unseen intra-Mercurial planet, Vulcan, was proposed.

That auxiliary repair did not succeed.

General relativity later explained the anomaly through a deeper theoretical change.

### FSP result

This case is especially important because it prevents an auxiliary-first bias.

The same repair topology that succeeded for Uranus cannot be privileged by rule.

FSP should represent a sequence such as:

```
baseline framework
-> anomaly
-> auxiliary repair candidate
-> unsuccessful evidential trajectory
-> auxiliary repair loses standing
-> deeper framework revision
```

This is exactly why TRANSLATION-3 and TRANSLATION-4 treat robustness as temporal and defeasible.

FSP can record the revision history.

It cannot derive, in advance, that the correct move is "add Neptune" in one case but "replace Newtonian gravity" in the other.

## 5. Quine's wider web

Quine generalizes the holist insight beyond Duhem's restricted philosophy of physical theory.

On a sufficiently holistic picture, revision may occur widely across the web of commitments.

### FSP result

The strongest FSP analogue is not one auxiliary list.

It is a network of:

- claims;
- evidence;
- warrants;
- background commitments;
- ontology commitments;
- tasks;
- auxiliary assumptions;
- translation relations;
- standing;
- consequences;
- REOPEN conditions.

A perturbation can therefore propagate across multiple represented layers.

This gives FSP a way to model **where revision pressure travels**.

But FSP does not endorse the stronger statement that literally any commitment can always be preserved by suitable adjustment.

The architecture permits:

- failed repair;
- irreducible translation failure;
- task-relevant divergence;
- claim-ceiling contraction;
- framework replacement.

That keeps FSP closer to a testable governance model than to an unrestricted holism thesis.

## 6. Contrastive underdetermination

Suppose two frameworks retain the same defined task-relevant empirical/practical signature while differing ontologically.

TRANSLATION-2 through TRANSLATION-4 support the candidate conclusion:

> Task success does not by itself license ontological uniqueness.

This is an FSP underdetermination result.

It is task-relative and perturbation-relative.

It is not the claim that the two theories are globally equivalent.

## 7. What FSP adds

The Duhem–Quine problem identifies underdetermination.

FSP adds representational governance around it.

It can make explicit:

- which auxiliary changed;
- which warrant was used;
- which background commitment is carrying inference;
- which evidence is shared;
- which remainder remains untranslated;
- which task is being evaluated;
- whether the same action rests on different reasons;
- whether institutional power is being confused with epistemic authority;
- when a previous result must REOPEN.

This does not eliminate underdetermination.

It makes its structure inspectable.

## 8. What FSP does not solve

FSP currently does not provide:

- a unique rational rule for choosing which belief to revise;
- a proof that all empirically equivalent theories are translatable;
- a proof that all rival ontologies can be represented in a common metalanguage without loss;
- a universal measure of theoretical simplicity;
- a universal account of scientific good sense;
- a proof of realism or antirealism;
- a proof of the Duhem–Quine thesis.

These are claim ceilings, not defects to conceal.

## 9. Strongest current interpretation

The strongest present FSP contribution is:

> FSP converts important forms of Duhemian and Quinean underdetermination from an undifferentiated philosophical problem into a governed, task-relative revision space in which auxiliary assumptions, evidence, warrants, translation loss, and reopening conditions can be represented and tested without pretending that the representation itself uniquely determines theory choice.

That is a significant result even if underdetermination remains.
