# FSP-ENCYCLOPEDIA-SCOPE-1

## Universal Core, Domain Libraries, Canonical Ownership, Course/Book Routes, Resource Depths, Public Status, and Cross-Domain Governance

### Scope correction

The scientific-inquiry collection is the first mature public collection of the FSP Encyclopedia.

It is **not** the scope definition of the Encyclopedia.

The Encyclopedia is defined as:

```text
FSP CORE
   ↓
DOMAIN LIBRARIES
   ↓
CANONICAL RESOURCES
   ↓
ROUTES / PROJECTIONS
   ↓
BOOKS · COURSES · LABS · VR · APPLICATIONS · RESEARCH
```

### Universal core

The initial shared core contains:

- Doing
- Map / World / Person
- Claim
- Evidence
- Provenance
- Standing
- Authority
- Possibility
- Transition
- Remainder
- Claim Ceiling
- REOPEN
- Authorial Return

This is a constitutional grammar, not a complete ontology for every domain.

### Domain libraries

The initial registry contains:

- FSP Core
- Inquiry & Science
- Ethics
- History of Philosophy
- Logic & Argument
- Aesthetics
- Institutions & Connected Doing
- Formal & Executable FSP

Each domain declares its own native topology.

The governing firewall is:

> **Shared FSP grammar does not imply shared domain ontology.**

### Canonical ownership

One resource has one canonical owner.

Routes, books, courses, VR scenes, and applications may select, compress, annotate, or project a canonical resource. They may not create an independent competing canonical version without an explicit REOPEN of ownership.

Shared historical figures should prefer one reusable historical master.

Example:

```text
ARISTOTLE — historical master
   ├─ Ethics aperture
   ├─ Logic aperture
   ├─ Aesthetics aperture
   └─ History-of-Philosophy route
```

### Routes

Books and courses become routes through canonical resources.

A route may cross domains.

Examples:

- Historical Ethics
- Intro Ethics
- Philosophy of Science
- History of Philosophy
- Logic & Argument
- Aesthetics
- Power & Flourishing Laboratory
- Three-Transformation Corridor

Route ≠ canonical owner.

### Resource depths

Three presentation depths are frozen:

- QUICK — orientation/recovery
- STANDARD — full readable account
- DEEP — source-rich/formal/controversy-aware

Depth may compress presentation.

Depth may not alter canonical identity, provenance, claim ceiling, historical sequence, or domain-native meaning.

### Public status

Resources and domains may declare statuses such as:

- SCOPED
- CANONICAL
- NARRATIVE
- ATLAS
- DEEP_READER
- CLASSROOM
- VR
- APPLICATION
- RESEARCH

Public status should drive discoverability.

### Governance rules

1. The Encyclopedia is broader than any one domain library, book, course, application, or projection.
2. Shared FSP grammar does not imply shared domain ontology.
3. Domain-native objects remain primary where the universal core is too thin.
4. One canonical resource has one canonical owner.
5. Shared historical figures/texts prefer one historical master plus domain apertures.
6. Course/book route ≠ canonical ownership.
7. Depth changes presentation, not semantics.
8. Public status must drive discoverability.
9. Cross-domain edges must remain typed.
10. New domains may extend ontology when fidelity requires it.
11. Whole↔part return must work at resource, domain, route, and Encyclopedia scales.
12. Production maturity does not imply philosophical priority.

### Claim ceiling

FSP-ENCYCLOPEDIA-SCOPE-1 freezes a multi-domain scope constitution.

It does not yet integrate the full Ethics, History of Philosophy, Logic, or Aesthetics resources into the public shell.

Those integrations should inherit this scope architecture rather than redefining it.
