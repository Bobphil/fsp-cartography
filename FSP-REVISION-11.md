# FSP-REVISION-11

## Legitimacy Under Emergency/Constraint, Temporary Floor Exceptions Audit, Sunset/Review Architecture, Non-Ideal Authorization, and Restoration-to-Normal-Governance Test

**Status:** Emergency-governance stress-test layer  
**Boundary:** REVISION-1 through REVISION-10 remain intact; TRANSLATION-12 human evidence remains PENDING.

## 1. Purpose

REVISION-10 established protected capability floors, burden-shifting limits, repair legitimacy, and plural authorization.

REVISION-11 asks the constitutional stress-test question:

> What happens when ordinary governance is genuinely insufficient under emergency conditions?

The danger is obvious: a framework built to preserve standing, contestability, and protected floors may simply suspend those protections when pressure rises.

REVISION-11 therefore permits only a narrowly bounded exception architecture.

## 2. Emergency condition

An emergency condition records:

- severity;
- visible evidence;
- affected groups;
- whether ordinary governance is insufficient;
- urgency;
- alternatives considered.

Emergency labeling alone does not create authority.

## 3. Temporary floor exception

A protected capability floor remains the default.

A temporary exception must identify:

- the exact floor;
- affected group;
- exact temporary restriction;
- necessity rationale;
- less restrictive alternatives;
- residual capability;
- start;
- sunset;
- independent review;
- minority-report preservation;
- restoration plan.

The exception does not create a new permanent floor.

## 4. Necessity

An exception is blocked when:

- ordinary governance remains sufficient;
- no necessity rationale is supplied.

Emergency convenience is not necessity.

## 5. Less restrictive alternatives

If a represented less restrictive alternative remains available, the exception is blocked.

The system therefore enforces:

```
emergency pressure
!=
permission to choose the most rights-restrictive path
```

## 6. Residual capability

A temporary restriction may narrow a protected capability.

It may not erase the capability entirely.

A legitimate exception must leave some residual capability such as:

- independent review;
- written objection;
- retrospective review;
- later REOPEN.

## 7. Sunset

A valid exception must have:

`sunsetOrdinal > startOrdinal`.

No indefinite emergency exception is permitted at creation.

## 8. Independent review and minority reports

Emergency action does not remove the need for:

- independent review;
- minority-report preservation.

These safeguards become more important under constraint, not less.

## 9. Sunset/review architecture

A sunset rule contains:

- interim review points;
- automatic expiration;
- new authorization for renewal;
- new evidence for renewal;
- independent review for renewal.

A temporary exception may not silently self-renew.

## 10. Renewal

Renewal is not continuation by inertia.

It requires:

- new authorization;
- new evidence;
- independent review.

The prior emergency finding is not sufficient by itself.

## 11. Non-ideal authorization

Emergency conditions may make ideal representation impossible.

A non-ideal authorization audit can therefore recognize:

- directly represented groups;
- unavailable groups;
- proxy representation;
- independent review;
- retrospective review.

But this produces only:

`TEMPORARILY_AUTHORIZED_UNDER_CONSTRAINT`.

It does not produce normal authorization.

## 12. Proxy standing

Proxy representation is allowed only for a group that is genuinely unavailable under the represented emergency.

It does not erase the need for retrospective review when ordinary participation becomes possible again.

## 13. Coercion remains a blocker

Emergency conditions do not convert severe coercion into legitimate authorization.

If authorization is obtained under severe coercion, the result remains:

`BLOCKED_COERCION`.

## 14. Missing affected groups

If an affected group is neither represented nor validly proxied, authorization is blocked.

Emergency urgency does not authorize exclusion by default.

## 15. Restoration plan

Every temporary exception must point to a restoration plan.

A restoration plan contains:

- exception IDs;
- restoration steps;
- restoration evidence;
- normal governance conditions to restore;
- a restoration deadline;
- post-restoration REOPEN.

## 16. Restoration-to-normal-governance test

Restoration succeeds only when:

- restoration steps are complete;
- normal governance conditions are restored;
- emergency exceptions are no longer active.

The result is then:

`RESTORED_TO_NORMAL_GOVERNANCE`.

## 17. Failure and normalization

If the restoration deadline passes while:

- emergency exceptions remain active; and
- normal governance remains unrestored,

the system returns:

`EXCEPTION_NORMALIZED`.

This is the central anti-ratchet safeguard.

A temporary exception that simply persists is not reclassified as legitimate normal governance.

## 18. Failed restoration

If the deadline passes and restoration is incomplete, but the emergency exception is not itself still active, the result is:

`FAILED_RESTORATION`.

This distinguishes governance failure from direct normalization of emergency powers.

## 19. Emergency persistence does not justify continuation

The restoration audit freezes:

`emergencyPersistenceJustifiesContinuation = false`.

Long duration is not self-justification.

## 20. Return to ordinary governance

The architecture therefore requires:

```
emergency
-> bounded exception
-> review
-> sunset
-> restoration
-> retrospective audit
-> ordinary governance
-> REOPEN
```

rather than:

```
emergency
-> exception
-> institutional sedimentation
-> permanent new normal
```

## 21. Human-validation boundary

Nothing in REVISION-11 changes TRANSLATION-12.

Human-validation status remains:

`PENDING`.

## 22. Research ceiling

The strongest current claim is:

> FSP can represent bounded emergency exceptions to protected governance conditions while requiring necessity, less-restrictive-alternative review, residual capability, independent oversight, sunset, non-self-renewal, and explicit restoration to normal governance, with a specific failure state for emergency powers that become normalized.

It does not establish a complete theory of emergency powers, constitutional law, public health ethics, or non-ideal political legitimacy.
