# FSP-VR-HORIZON-RETENTION-REVIEW-1

## Accelerate → Inspect → Pin → Freeze: Distant Possibility as Present Horizon versus Sophisticated Graph

**Status:** EXPERIENCE REVIEW / HORIZON-RETENTION DIAGNOSTIC — VERSION 1  
**Parents:** FSP-VR-MAATHAI-FIELD-2; FSP-VR-FIELD-EXPERIENCE-REVIEW-1; FSP-VR-TEMPORAL-LENS-1  
**Review sequence:** ACCELERATE → inspect P-ADVOCATE → pin → FREEZE  
**Primary question:** Does the distant possibility remain experientially available as part of the frozen present's horizon, or merely persist as a graphical object / memory trace?

# 1. Why This Review Is Harder Than FIELD-2's Field-Like Threshold

FIELD-2 passed the code-level field-experience threshold because it supports:
- temporal breathing;
- path-borne contingencies;
- gate thresholds;
- persistent traces;
- reversible zoom;
- comparative pinning.

But persistence alone is insufficient.

A distant path can remain in application state while failing experientially because:
- it is clipped by the viewport;
- its endpoint disappears;
- its contingency beads become too faint or too distant;
- its relation to the present becomes visually ambiguous;
- it looks like a selected graph edge rather than a future that remains conditionally reachable.

Therefore:

> **Persisting object ≠ retained horizon.**

# 2. Horizon-Retention Trial

Use one fixed sequence:

1. Start in NORMAL.
2. ACCELERATE.
3. Inspect **Publicly advocate for change**.
4. Expand its gate.
5. Pin the path.
6. FREEZE.
7. Do not reset.
8. Inspect what remains visible.

The learner should then be able to answer without reopening ACCELERATE:

- What distant possibility did I inspect?
- Why is it distant?
- Which conditions are already present?
- Which are absent or unknown?
- How is it still connected to the current 1976 field?
- What would have to change for it to move inward?

# 3. Graph-Like Failure Signatures

The trial remains graph-like if:

- the ghost survives only as opacity state;
- the terminal possibility is clipped outside the visible field;
- prerequisite beads remain at their original distant coordinates and become hard to read;
- the path does not visually distinguish “outside current horizon but retained” from “currently live”;
- the ghost has no explicit tether to the present;
- the user must rely on the side-panel comparison row to remember what the ghost means;
- clicking the ghost does not provide a natural route back outward;
- Freeze magnifies the present at the cost of losing the retained horizon.

# 4. Horizon-Like Success Signatures

The distant possibility should remain:

## H1 — Visibly tethered

A continuous or compressed relation should still connect the frozen present to the retained future.

## H2 — Conditionally legible

At least the decisive contingency structure should remain visible:
- present conditions;
- blocking condition;
- unresolved / unknown condition.

## H3 — Inside the perceptual field

The retained horizon marker must remain within the viewport after Freeze.

A ghost that is technically rendered outside the view does not count.

## H4 — Distinct from current reachability

The ghost should visibly mean:

> “remembered / conditionally reachable beyond the current focal horizon”

not:

> “currently available now.”

## H5 — Re-enterable

The learner should be able to select the ghost and naturally reopen / widen temporal depth toward it.

## H6 — Present-relative

The ghost should preserve its relation to the current 1976 capabilities and constraints, not float as an isolated future node.

## H7 — Recomposition-supporting

After returning inward, the retained horizon should help the learner explain what would have to change in the present for the distant possibility to become nearer.

## H8 — Non-predictive

Retention must not imply:
- expected future;
- correct path;
- recommendation;
- historical destiny.

## H3 — Inside the perceptual field

**0 / 2**

FIELD-2 Freeze uses a view scale of 1.34.

The depth-4 advocacy endpoint sits at approximately radius 430.

430 × 1.34 = 576.2 units before accounting for the endpoint node radius.

The SVG viewBox half-width is 560.

Therefore the pinned terminal endpoint can be clipped during Freeze.

This is a direct experiential failure even though state retention passes.

But selection does not automatically reopen temporal depth or animate outward toward the retained future.

## H6 — Present-relative

But the retained future does not reorganize itself around the enlarged frozen present.

## H7 — Recomposition-supporting

## H8 — Non-predictive

- distance ≠ probability;

- no historical “correct” path.

# 8. The Core Design Problem

Freeze currently performs one geometric operation globally:

> enlarge the field around the present.

That operation improves near-field inspection but also pushes distant retained paths outward.

The next geometry needs two simultaneous transforms:

1. **present expansion** for near-field depth;
2. **horizon compression / anchoring** for retained distant possibilities.

This suggests a non-Euclidean or multi-scale visual field.

The present can expand without forcing remembered distant futures off-screen.

# 9. Next Required Geometry

A retained distant path should transform under Freeze into a **horizon tether**:

central present  
→ compressed remembered contingency chain  
→ horizon marker

The endpoint should sit on an inner visible horizon band, not at its original depth-4 radius.

The path preserves:
- original temporal depth;
- contingency order;
- missing conditions;
- unknowns.

But spatial distance is compressed while Freeze is active.

This is not a claim that the future has become nearer in historical time.

It is a memory / inspection transform.

> **Inspection compression ≠ temporal nearness.**
