### Reader depth

Progressive disclosure is frozen as:

- **READ** — prose, case cards, concepts, plain-language ceilings, return.
- **INSPECT** — states, transitions, probes, source support, tools, comparisons.
- **FORMAL** — canonical fields, transition dimensions, formal comparisons, invariants.

Depth changes presentation density only. It may not change canonical object identity or inferential strength.

### Sources

Canonical authority remains `CanonicalCaseDossier.sourceLedger`.

Public source views may improve explanation and discoverability but may not replace claim-level provenance with an undifferentiated bibliography.

### Return

Public deep inspection preserves:

- origin public object;
- section/anchor when applicable;
- reader depth;
- comparison context when applicable;
- navigation history.

A comparison-origin journey returns to the comparison. A prose-origin journey returns to the prose context. Generic-home fallback is not an acceptable substitute when an origin token exists.

## Constitutional rules

1. Public architecture indexes and explains canonical objects; it does not redefine Atlas field semantics.
2. Chapter-to-Atlas semantic edges remain governed by `encyclopediaNavigation.ts`.
3. Concept and tool links are explanatory overlays, not new evidence or historical claims.
4. Reader depth changes presentation density, not canonical object identity or claim strength.
5. Shared comparison grammar does not imply historical sameness.
6. Counterfactual probe output remains distinct from sourced historical actuality.
7. Every public path that deepens inspection preserves an Authorial Return route.
8. No public presentation may exceed the applicable canonical claim ceiling.
