# FSP-VR-MAATHAI-FIELD-3

## Dual-Scale Present/Horizon Geometry; Horizon Tethers; Contingency Compression; Re-entry Animation; Retained-Future Band; Present-Relative Recomposition; and Horizon-Retention Regression

**Status:** NON-DEPLOYED EXPERIENCE-LAYER PROTOTYPE — VERSION 3  
**Parents:** FSP-VR-MAATHAI-FIELD-2; FSP-VR-HORIZON-RETENTION-REVIEW-1  
**Historical semantics:** unchanged  
**Primary problem:** preserve deep present inspection and distant conditional futures in the same perceptual field.

# 1. Governing Geometry

FIELD-3 separates two visual transforms:

1. **Present-space transform**
   - expands near-field detail during Freeze;
   - preserves local institutions, loci, and immediate paths.

2. **Retained-horizon transform**
   - compresses pinned out-of-range futures onto a visible horizon band;
   - preserves direction, path identity, decisive contingencies, and uncertainty.

> **Inspection compression ≠ temporal nearness.**

# 2. Retained-Future Band

Pinned paths outside the active temporal depth are not drawn at their original radius.

Instead, they are remapped to a bounded horizon radius.

Initial contract:

- horizon radius: 385;
- marker radius: 24;
- marker must remain inside the SVG viewport at all modes;
- marker style must differ from currently reachable path endpoints.

# 3. Horizon Tether

A retained distant path becomes:

**present locus → compressed tether → retained-future marker**

The tether preserves:
- original angular direction;
- original temporal depth metadata;
- contingency state;
- path identity.

The visual distance is compressed only for inspection.

# 4. Contingency Compression

A distant path may have many prerequisites.

In retained-horizon mode, show at most four representative checkpoints:

1. first PRESENT condition;
2. first PARTIAL condition;
3. first ABSENT condition;
4. first UNKNOWN condition.

Missing categories are omitted.

Order follows original path order.

# 5. Distinct Horizon State

Retained-horizon markers must visually encode:

> remembered / conditionally reachable beyond the current focal horizon

They must not look like:
- current options;
- recommendations;
- predictions;
- completed outcomes.

# 6. Re-entry Animation

Selecting a retained-horizon marker should:

1. select that path;
2. animate temporal mode outward to the minimum mode needed to make its true depth visible;
3. restore the full original path geometry;
4. preserve prior pins and trace history.

For depth 4:
- re-entry target = ACCELERATE.

# 7. Present-Relative Recomposition

While Freeze is active, the retained horizon marker should support the question:

> What would have to change in the present for this possibility to move inward?

The compressed tether should therefore preserve enough contingencies to answer without leaving Freeze.

# 8. Dual-Scale Invariant

Freeze may enlarge the present.

It may not push a pinned distant future outside the visible field.

Therefore:

> **near-field expansion and horizon retention must be geometrically independent.**

# 9. Horizon-Retention Acceptance

FIELD-3 targets:

- H1 visible tether ≥ 1
- H2 conditionally legible = 2
- H3 inside perceptual field = 2
- H4 distinct from current reachability = 2
- H5 re-enterable ≥ 1
- H6 present-relative ≥ 1
- H7 recomposition-supporting ≥ 1
- H8 non-predictive = 2
- total ≥ 12 / 16

# 10. Claim Ceiling

FIELD-3 can demonstrate that the renderer supports horizon-retention mechanics.

It cannot establish that users phenomenologically experience the marker as a lived future horizon.

Human visual testing remains necessary.
