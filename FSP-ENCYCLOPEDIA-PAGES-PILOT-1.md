# FSP-ENCYCLOPEDIA-PAGES-PILOT-1

## CH1.2 Neptune/Vulcan GitHub Pages Pilot

This build makes the first certified Encyclopedia reader publicly deployable as a GitHub Pages site.

### Bound route

The pilot is constitutionally fixed to:

`CH1.2 → NEPTUNE-VULCAN`

The frozen contextual aperture remains:

- `NV0-NV1`
- `NV1-NV2`
- `NV3-NV4`
- `NV-PROBE-VULCAN`
- `NEPTUNE-VULCAN` case claim ceiling

No deployment code creates or expands semantic routes.

### Production path

`site/index.html` is the static Pages entry page.

`src/research/encyclopediaPilot.ts` mounts the already-certified browser reader.

`src/research/encyclopediaPilotConfig.ts` contains the pilot binding and prose.

The Pages workflow runs the complete regression suite and browser compilation before bundling with esbuild. Deployment cannot proceed unless the build job succeeds.

### Claim ceiling

This pilot certifies a real browser-accessible path only after the Pages workflow completes and the deployed URL is verified. It does not yet establish Pressbooks embedding, all-chapter production, or broad human usability certification.
