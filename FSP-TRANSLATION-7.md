# FSP-TRANSLATION-7

## External-Corpus Reconstruction, Rival-Formalism Comparator Set, Independent Case Coding, and Submission-Scale Paper Architecture

**Status:** External-source comparative research layer  
**Canonical mode:** Monograph-scale repository; submission-scale papers are derived exports only.

## 1. Purpose

TRANSLATION-7 moves the program outside exclusively FSP-authored cases.

The build adds:

- an external AIF/xAIF reconstruction adapter;
- a real external argumentation sample and public-corpus registry;
- a rival-formalism comparator set;
- an independent-coding agreement protocol;
- a canonical research architecture that protects the full repository from arbitrary submission word limits.

The central methodological principle is:

> Publication formats may compress the research presentation, but they must not compress the canonical research object itself.

## 2. Canonical repository policy

The canonical FSP research repository is explicitly **MONOGRAPH_SCALE**.

No journal, conference, or venue word count may determine:

- what conceptual distinctions are retained;
- what failure history is preserved;
- which comparator results remain available;
- whether extended cases are deleted;
- whether alternative hypotheses are documented;
- whether claim ceilings and REOPEN conditions remain visible.

Submission-scale papers are exports from the canonical repository.

They are not the canonical repository.

## 3. External argumentation source

TRANSLATION-7 uses the ARG Tech AIF/xAIF framework as an external representational source.

AIF distinguishes:

- locution nodes (L);
- information nodes (I);
- inference relations (RA);
- conflict relations (CA);
- rephrase relations (MA);
- transition and anchoring structures;
- participant attribution.

The build reconstructs a public tutorial example independently of FSP and records public AIF corpus identifiers for later corpus-scale work.

This is important because the external representation was not designed to confirm FSP.

## 4. External reconstruction claim ceiling

This build does **not** claim corpus-scale QT30 ingestion.

It establishes:

- successful reconstruction of an externally specified AIF sample;
- preservation of native AIF distinctions;
- an adapter capable of identifying what AIF natively represents and what FSP would add.

The public corpus registry marks QT30 and AIFdb resources as future external-scale targets.

## 5. Rival formalism set

TRANSLATION-7 now compares three representational strategies.

### CEA

Claim–Evidence–Action.

Strength:

- compact;
- retains basic propositional and practical structure.

Loss:

- no relation typing;
- no explicit task governance;
- no claim ceiling;
- no standing;
- no remainder;
- no auxiliary support;
- no agency audit.

### AIF

Argument Interchange Format.

Strength:

- locution/content distinction;
- propositional information nodes;
- argument relation types;
- participant attribution;
- graph-structured argumentative relations.

Its native task is argument representation, not FSP governance.

Therefore FSP must not criticize AIF for failing to include structures it was not designed to represent.

The proper comparator question is:

> What additional work does FSP perform when the inquiry task requires task bounds, standing, translation remainder, claim ceilings, auxiliary assumptions, agency, or REOPEN?

### FSP

FSP retains:

- claim/evidence/action where relevant;
- task identity;
- warrant;
- background;
- claim ceiling;
- ontology;
- standing;
- translation remainder;
- auxiliary support;
- agency;
- REOPEN.

The comparison is functional rather than triumphalist.

## 6. Independent coding

An external reconstruction should not count as validated merely because one FSP coder generated it.

TRANSLATION-7 therefore defines two independent coding records.

Core agreement requires:

- at least 0.66 information-node overlap;
- relation-type agreement;
- participant agreement.

Task inference and translation remainder are recorded separately because they go beyond native AIF representation.

This distinction is important:

> agreement on native source structure is not the same as agreement on FSP interpretation.

## 7. Reconstructive layers

External cases should therefore be processed in layers:

1. **native reconstruction** — preserve the external formalism as faithfully as possible;
2. **independent coding check** — test agreement on recoverable native structure;
3. **FSP augmentation** — add task, standing, claim ceiling, remainder, auxiliary, and agency only where justified;
4. **comparator audit** — record what each formalism preserves or omits;
5. **claim ceiling** — distinguish native-source result from FSP interpretation.

## 8. Why this matters philosophically

This protects the ontological-agnostic project from an important circularity.

If every case is first rewritten in FSP terms, then later “success” may simply show that FSP can represent cases already designed in FSP.

External reconstruction introduces resistance.

The source has its own:

- ontology;
- data model;
- representational purpose;
- distinctions;
- omissions;
- failure modes.

FSP must translate from that independent structure rather than assume its own categories are already present.

## 9. Submission-scale architecture

TRANSLATION-7 makes a sharp distinction between:

### Canonical research object

Unlimited by arbitrary publication length.

Contains:

- complete formal specifications;
- all test results;
- failure and repair histories;
- full comparator analyses;
- long case reconstructions;
- ablations;
- alternative hypotheses;
- philosophical implications;
- future research branches.

### Journal article export

A bounded argument selected from the canonical object.

Must:

- specify the target question;
- preserve only evidence needed for that claim;
- maintain an omitted-material ledger;
- never delete canonical research merely to satisfy venue length.

### Conference export

One demonstrative result with explicit return pointers to the canonical architecture.

### Monograph

The natural form when the research argument requires:

- developmental history;
- multiple domains;
- rival formalisms;
- formal results;
- philosophical interpretation;
- VR consequences;
- normative architecture.

## 10. Publication discipline without publication compression

Publication standards remain useful because they force:

- explicit claims;
- comparator engagement;
- falsification criteria;
- source provenance;
- claim ceilings;
- clear division between result and speculation.

But they do not set the ontology of the research project.

The canonical question is:

> What do we need to understand this adequately?

not:

> What can fit into 8,000 words?

## 11. Current strongest claim

After TRANSLATION-7, the strongest warranted claim remains comparative and provisional:

> FSP has replicated across three constructed domains, preserves task-governance structures lost by simpler CEA projection, adds governance structures not native to AIF, and can reconstruct an independently specified AIF sample while keeping native-source representation distinct from later FSP augmentation.

This is stronger than an internal demonstration.

It is not yet:

- corpus-scale AIF validation;
- independent empirical replication;
- universal PRF translatability;
- proof of Duhem–Quine;
- human-fidelity validation.

## 12. FSP-VR implication

This external-source discipline is essential before deeper VR work.

VR is especially capable of making reconstruction feel more complete than it is.

Therefore every future experiential exemplar should be able to distinguish:

- native evidence;
- source reconstruction;
- FSP-added interpretation;
- translation remainder;
- unknowns;
- disputed coding.

The user should never confuse experiential vividness with evidential completeness.

## 13. Next ceiling

The next genuine advance would be corpus-scale and externally resistant:

- import raw AIF nodesets from multiple public corpora;
- preserve original node IDs;
- perform independent FSP coding against those real graphs;
- compare AIF-native queries with FSP-added queries;
- run compression ablation;
- test whether the same added fields remain useful at corpus scale.

The canonical repository should continue to retain the full result regardless of later publication format.
