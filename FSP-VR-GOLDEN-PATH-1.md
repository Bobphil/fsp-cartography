# FSP-VR-GOLDEN-PATH-1

## Pedagogical Zero; Minimal Doing; Embodied Control; Other Agency; Dependency; Expectation Failure; Freeze; Temporal Trace; REOPEN; Social Evaluation; Evidence Inspection; Claim Ceiling; Scaffold Fading; Life-Lottery Handoff; and Experiential-Operation Regression

**Status:** NON-DEPLOYED END-TO-END LEARNING-LOOP PROTOTYPE — VERSION 1  
**Parents:** FSP-VR-DEVELOPMENTAL-ENTRY-1; FSP-VR-EXPERIENTIAL-GRAMMAR-1  
**Primary purpose:** prove that a short FSP-VR sequence can teach a reusable inquiry grammar through experience rather than exposition.

# 1. Golden-Path Question

Can a framework-naive learner move through one short experience and acquire enough of the FSP interaction grammar to:

1. distinguish action, control, influence, and other agency;
2. recognize expectation failure;
3. use Freeze to create extra epistemic time;
4. inspect temporal traces;
5. REOPEN a failed map;
6. separate observation from interpretation;
7. encounter a claim ceiling;
8. begin using operations with reduced prompting;
9. arrive at the Life Lottery with a usable grammar of situated Doing?

# 2. Governing Experience Loop

**LIVE → NOTICE → ACT → EXPERIENCE CONSEQUENCE → FREEZE → DECOMPRESS → INSPECT → RECONSTRUCT → RETURN → ACT AGAIN**

No scene counts as complete merely because explanatory text has appeared.

# 3. Golden Path

## GP0 — Pedagogical Zero

Learner sees:
- near-empty field;
- one event;
- no FSP terminology.

Learner does:
- orient toward event.

Operation:
- TURN / RELOCATE attention.

Learner should discover:
- experience is situated.

Scaffold:
- no labels.

## GP1 — Minimal Doing / Embodied Control

Learner sees:
- one controllable hand-like locus;
- one independent inert object.

Learner does:
- move / reach.

Operation:
- REACH / ACT.

Sensory signature:
- successful action gets a light confirmation cue;
- inert object does not.

Learner should discover:
- some changes covary with action.

Firewall:
- control ≠ complete theory of agency.

## GP2 — Resistance and Other Agency

Learner sees:
- resistant object;
- independently moving other agent.

Learner does:
- attempt control;
- signal / wait.

Operations:
- ENCOUNTER RESISTANCE;
- SIGNAL / WAIT.

Learner should discover:
- controlled ≠ uncontrolled;
- MY DOING ≠ OTHER DOING;
- influence ≠ control.

## GP3 — Dependency

Learner experiences:
- need-state cue;
- signaling action;
- caregiver response that is probable but not guaranteed.

Operation:
- SIGNAL / WAIT.

Learner should discover:
- agency and dependence coexist.

Firewall:
- dependence ≠ inferiority.

## GP4 — Expectation Failure

Sequence repeats:
- signal → response;
- signal → response;
- signal → no response.

The system does not automatically explain the failure.

A subtle anomaly cue appears.

Target learner move:
- invoke FREEZE.

If learner does not act after bounded delay:
- Level 3: explicit "Freeze?"
- Level 2: icon cue;
- Level 1: anomaly pulse only;
- Level 0: no cue.

This is the first scaffold-fading test.

## GP5 — Freeze / Temporal Trace

Freeze must:
- stop motion;
- reduce auditory flow;
- retain current state;
- reveal previous traces;
- increase relation inspectability.

Learner can compare:
- prior successful episodes;
- current failed episode.

Operations:
- FREEZE / EXPAND;
- TRACE BACKWARD.

Learner should discover:
- regularity ≠ necessity;
- expectation had an evidential history.

## GP6 — REOPEN

Learner selects the failed expectation.

The compact expectation map expands.

Learner can mark:
- what happened;
- what was expected;
- what is unknown;
- what should be revised.

Operation:
- OPEN / DRILL DOWN.

Meaning:
- failed map → reopen relevant structure, not entire world.

Return:
- revised expectation recomposes into active field.

## GP7 — Social Evaluation

Learner observes:
- one agent facilitating another;
- one agent obstructing another.

No moral valence colors.

Learner may express preference.

The system records response without marking it correct.

Operation:
- NOTICE / CHOOSE.

Target distinction:
- response/preference ≠ moral justification.

## GP8 — Evidence Inspection

Evidence objects become available only after learner response.

Co-present objects:
- original observation;
- interpretation;
- alternative explanation;
- replication;
- claim ceiling.

Operations:
- OPEN / DRILL DOWN;
- PLACE SIDE BY SIDE.

Learner can keep multiple evidence objects visible simultaneously.

Target distinction:
- observation ≠ interpretation;
- original result ≠ settled result.

## GP9 — Claim Ceiling

Learner is invited to test an overextended claim:

> "Infants sometimes chose a helper, therefore infants possess adult morality."

A visual inference line reaches a boundary.

Crossing remains possible only as clearly marked speculation.

Operation:
- HIT BOUNDARY.

Target distinction:
- evidence licenses only so much.

Firewall:
- replication failure ≠ proof of opposite.

## GP10 — Faded Scaffold Transfer

A structurally similar but content-light microcase appears.

The interface does not say:
- Freeze;
- inspect source;
- compare alternative;
- check ceiling.

The learner must choose operations.

This stage measures whether the grammar is beginning to become self-initiated.

Minimum target:
- one spontaneous inquiry operation before explicit prompt.

## GP11 — Return / Life-Lottery Handoff

The field recomposes.

Text:

> **Every human Doing develops somewhere.**

Then:

> **You do not choose where you begin.**

The learner retains learned operations.

Handoff:
- FSP-VR-SITUATED-ENTRY / LIFE LOTTERY.

# 4. Scaffold Fading Contract

Scaffold levels:

**L3 — Explicit**
- textual prompt + icon + highlighted control.

**L2 — Suggested**
- icon + concise prompt, no procedural instruction.

**L1 — Cue**
- sensory/icon cue only.

**L0 — Independent**
- no cue.

Each operation must be capable of moving toward L0.

# 5. Golden-Path Operations

Required operations:

- TURN / RELOCATE;
- REACH / ACT;
- ENCOUNTER RESISTANCE;
- SIGNAL / WAIT;
- FREEZE / EXPAND;
- TRACE BACKWARD;
- OPEN / DRILL DOWN;
- PLACE SIDE BY SIDE;
- HIT BOUNDARY;
- RECOMPOSE / RETURN.

Optional later:
- oracle;
- haptic hardware-specific variants;
- spatial audio beyond browser stereo simulation.

# 6. Experiential-Operation Contract

Every golden-path scene must answer:

1. What does the learner perceive?
2. What can the learner do?
3. What changes when they do it?
4. Which sensory cue carries the distinction?
5. How can they inspect it more deeply?
6. How would misunderstanding be detected?
7. How do they return to ordinary Doing?

A scene fails the golden-path contract if any answer is missing.

# 7. Misunderstanding Detection

Examples:

**Control failure**
Learner treats other agent as controllable object.

**Dependency failure**
Learner interprets successful signaling as guaranteed command.

**Freeze failure**
Learner treats Freeze as pause rather than deeper inspection.

**Trace failure**
Learner confuses past trace with current state.

**Evidence failure**
Learner treats interpretation as observation.

**Ceiling failure**
Learner interprets boundary as censorship rather than evidential limit.

**Transfer failure**
Learner waits indefinitely for explicit prompt in GP10.

# 8. Memory / Habit Formation Hypothesis

Golden Path does not claim durable transfer.

It creates conditions for testing it by pairing recurring distinctions with:

- stable visual signatures;
- stable operations;
- motor actions;
- temporal manipulations;
- repeated consequences;
- scaffold fading.

Hypothesis:

> repeated multimodal operations may become retrievable inquiry habits outside the original scene.

This requires later human testing.

# 9. Claim Ceiling

Golden Path can establish:
- deterministic scene sequence;
- experiential-operation completeness;
- scaffold-fading mechanics;
- state persistence;
- browser-level interaction semantics.

It cannot establish:
- lived presence;
- haptic effectiveness;
- durable memory;
- transfer outside VR;
- improved critical thinking.

Those require human testing.

# 10. Acceptance

Golden Path passes code-level acceptance when:

- all 12 stages exist in order;
- every stage satisfies experiential-operation contract;
- GP4 supports L3→L0 Freeze fading;
- GP5 exposes at least two past traces and current failed trace;
- GP6 supports map revision;
- GP8 keeps observation / interpretation / alternative / replication / ceiling distinct;
- GP9 blocks clean evidential propagation past ceiling;
- GP10 contains no explicit procedural prompt;
- GP11 preserves acquired-operation state into Life-Lottery handoff;
- prototype remains non-deployed;
- CODE-0.1 is green.
