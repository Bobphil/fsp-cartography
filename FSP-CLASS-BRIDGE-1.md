# FSP-CLASS-BRIDGE-1

## Course / Workbook / Output-Card Bridge

This build binds the certified classroom projection profile to a concrete instructional package grammar.

The classroom path is:

```text
canonical object
→ classroom projection package
→ course placement
→ workbook moves
→ output card
→ optional journal handoff
→ learner-authored return
```

The first package is `CLASS-NV-REVISION-1`, a 60-minute Philosophy of Science session using the certified Vulcan controlled-revision probe.

The workbook has four consequential moves:

1. map revision pressure;
2. hold/vary the auxiliary;
3. compare Neptune and Vulcan trajectories;
4. state a bounded judgment and REOPEN condition.

The output card requires student-authored claim, reason, uncertainty, and REOPEN.

The journal handoff is explicitly downstream and reflective. It may support transfer but may not replace or edit the bounded judgment already produced in the workbook.

This bridge is intentionally generic enough to support the existing FSP course ecology. Course-specific bindings can later map Ethics, History/Philosophy of Science, Intro Philosophy, or other packages into the same grammar without making one course the universal model.

### Claim ceiling

This build certifies classroom packaging structure, not instructional efficacy. Time budgets, prompt difficulty, rubric quality, and transfer remain testable.
