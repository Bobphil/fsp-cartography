# FSP-ENCYCLOPEDIA-PUBLIC-SHELL-1

## First Public Encyclopedia Shell

This build implements the certified public information architecture as an actual GitHub Pages shell.

### Public routes

The site now exposes stable hash routes for:

- `#/chapters`
- `#/cases`
- `#/concepts`
- `#/tools`
- `#/comparisons`

Detail pages are available under the corresponding IDs.

The shell is intentionally a public navigation and explanation layer. It does not create chapter↔Atlas semantic routes.

### First complete vertical slice

`#/reader/CH1.2/NEPTUNE-VULCAN`

mounts the already-certified interactive reader and remains the only case currently presented as a complete public vertical slice.

Other case, concept, tool, and comparison pages are honest index/detail surfaces that show the certified architecture without implying that their full deep-reader production is complete.

### Deployment

The existing Pages workflow continues to bundle `encyclopediaPilot.ts`, which now mounts the public shell. No server-side routing is required because public navigation uses hash routes.

### Claim ceiling

This shell certifies public discoverability and placement, not final visual polish, complete chapter prose, or complete deep readers for the remaining cases.
