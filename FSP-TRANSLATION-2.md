# FSP-TRANSLATION-2

## Four-PRF Forest Stress Test, Pairwise Translation Matrix, Underdetermination Candidate Theorem, Shared-Task Negotiation, Institutional Power Audit, and Capability-Preserving Repair

**Status:** Integrated adversarial research case  
**Boundary:** Research layer only. No Cartography kernel change.

## 1. Purpose

FSP-TRANSLATION-1 established isolated translation primitives. FSP-TRANSLATION-2 asks whether those primitives remain useful when four divergent PRFs occupy the same contested institutional problem at once.

The case is deliberately constructed so that success cannot mean "translate everybody into the same worldview."

The research questions are:

1. Can every directed PRF-to-PRF relation be represented without assuming symmetry?
2. Can the system preserve non-empty translation remainder while still identifying actionable overlap?
3. Can an underdetermination-like result be stated narrowly enough to test?
4. Can a shared task be negotiated rather than imposed?
5. Can an institution produce coordination while still generating serious domination risk?
6. Can a repair improve capability across affected PRFs without requiring ontological convergence?

## 2. Four PRFs

The test instantiates:

- **A — Ecological scientific naturalism**
- **B — Property / market framework**
- **C — Relational Indigenous ecological framework**
- **D — Religious stewardship framework**

These are intentionally simplified research constructs, not representations of all scientists, property-rights advocates, Indigenous peoples, or religious believers.

Each PRF is represented through its own salient entities, values, evidence, warrants, background commitments, standing, claim ceiling, and ontological commitments.

The test therefore concerns the formalism, not anthropological completeness.

## 3. Pairwise translation matrix

Four PRFs create twelve directed translation relations.

The matrix is directed because:

```
τ(A→C) != τ(C→A)
```

in general.

Every ordered pair must be present:

```
A→B A→C A→D
B→A B→C B→D
C→A C→B C→D
D→A D→B D→C
```

The matrix passes only when all twelve directed relations are explicitly represented.

The case intentionally includes:

- direct empirical overlap;
- structural translations;
- task-equivalent translations;
- non-empty remainder in every cross-ontology route where local equivalence would overstate what has been carried.

The matrix is not a similarity score.

It is a provenance-bearing record of what has and has not survived a bounded translation.

## 4. Candidate underdetermination theorem

FSP-TRANSLATION-2 operationalizes the first narrow underdetermination schema.

For a bounded task `T`, define the task-relevant evaluation signature:

```
E_T(PRF) =
  <empirical commitments,
   practical constraints,
   predicted consequences,
   licensed actions>
```

The candidate proposition is:

> If two PRFs are ontologically non-identical but share the same task-relevant evaluation signature for T, successful handling of T does not by itself license ontological uniqueness.

Formally:

```
O_A != O_B
and
E_T(PRF_A) = E_T(PRF_B)
therefore
T-success does not entail O_A = O_B
```

This is **not** presented as a proof of Duhem-Quine.

It is a candidate FSP theorem about the claim ceiling of task success.

The executable assessor therefore never returns "ontology proven." It returns only:

- **UNDERDETERMINATION_SUPPORTED**
- **NOT_ESTABLISHED**

The result is supported only when:

- the task is the same;
- ontological commitments differ;
- empirical commitments match;
- practical constraints match;
- predicted consequences match;
- licensed actions match.

If any task-relevant dimension differs, the candidate result is NOT_ESTABLISHED.

## 5. Forest task negotiation

The first proposed task is:

> Maximize economic value from the forest.

A, C, and D reject it.

The formalism must record that rejection rather than converting it into "partial cooperation."

A second proposal is:

> **Protect the watershed from irreversible damage while negotiating permissible land use.**

All four accept this bounded task for different reasons.

This is the central cooperation-without-convergence result.

A accepts because ecological viability is protected while inquiry continues.

B accepts because final land-use rules remain contestable rather than being predetermined.

C accepts because immediate destructive use is blocked while community and place-based standing are recognized.

D accepts because stewardship constraints are honored without requiring other parties to adopt a theological ontology.

The shared task therefore does not encode one common metaphysics.

It encodes a bounded coordination object that remains differently justified from within each PRF.

## 6. Institutional power audit

The stress case adds a County Land Use Board.

The initial institution is asymmetric:

- agenda control is concentrated;
- information control is concentrated;
- decision authority is concentrated;
- appeal is effectively available to B but not equally to the other participants;
- C has blocked interpretive contestability, participation, and reopenability;
- A and D have constrained participation and blocked reopenability.

The audit therefore separates three questions:

1. Can the institution produce a decision?
2. Can it coordinate participant behavior?
3. Does that coordination preserve enough agency to count as legitimate cooperation?

FSP-TRANSLATION-2 explicitly refuses to infer question 3 from questions 1 or 2.

## 7. Capability-preserving repair

The principal repair introduces:

- an open evidence docket;
- equal standing in task-definition hearings;
- a general appeal/reopen route;
- explicit interpretive contestability;
- participation support for materially constrained participants.

The repair is assessed PRF by PRF.

It passes only if at least one participant improves and no participant's agency audit worsens.

This is stronger than the single-agent repair test in TRANSLATION-1 because it prevents an "improvement" for one group from being hidden behind a loss for another.

A contrasting bad repair publishes more evidence but centralizes interpretation and removes appeal in the name of speed.

That repair must fail.

## 8. What the integrated case demonstrates

If the tests pass, FSP-TRANSLATION-2 establishes only the following:

- directed translation can be complete as a matrix without being lossless;
- translation remainder can coexist with local coordination;
- task-relative empirical/practical equivalence can coexist with ontological difference;
- shared tasks can be negotiated without metaphysical convergence;
- an institution can coordinate while still presenting domination risk;
- a repair can be tested for multi-party capability preservation.

It does not establish:

- that all ontologies are equally good;
- that evidence cannot rationally favor one ontology in another task;
- that all PRFs can translate into one another;
- that any shared task is morally sufficient;
- that the six agency dimensions exhaust domination;
- that the forest case models any actual Indigenous or religious community adequately.

## 9. Adversarial failure conditions

The build fails conceptually if:

- a missing directed pair is silently treated as translated;
- symmetric translation is assumed;
- equal task signatures are treated as global theoretical equivalence;
- shared-task acceptance is inferred from behavior alone;
- the institutional audit ignores who controls agenda, information, or appeal;
- repair benefits some participants by degrading another's agency;
- C's relational ontology is reduced to market value or ecosystem services;
- D's stewardship ontology is treated as disguised scientific naturalism;
- B's property concerns are treated as automatically illegitimate merely because they differ from A/C/D;
- FSP's categories become immune to participant contest.

## 10. Relationship to FSP-VR

This integrated case provides a concrete VR grammar.

A future learner could move among four bounded PRF spaces and see:

- the same watershed evidence embedded in different significance structures;
- pairwise translation lines whose preserved content and remainder differ by direction;
- a proposed shared task rejected in real time;
- a revised shared task accepted for non-identical reasons;
- an institution whose power topology is visible separately from its formal rules;
- a repair that redistributes access, contestability, standing, and reopenability;
- unchanged ontological divergence after cooperation becomes possible.

The visual lesson would be:

> cooperation can increase while convergence remains partial.

The philosophical lesson would be:

> successful joint action does not automatically settle what ultimately exists.

The political lesson would be:

> coordination is not sufficient evidence of legitimate agency.

## 11. Research ceiling

The Duhem-Quine bridge remains a research direction.

This build earns only a **candidate underdetermination result** at the task-relative level.

A later build must test whether the evaluation signature is too coarse, whether auxiliary assumptions need explicit representation, and whether empirically equivalent signatures remain equivalent under perturbation.

Recommended next question:

> Does the candidate theorem survive when evidence changes, auxiliary assumptions diverge, and one PRF predicts a consequence the others do not?
