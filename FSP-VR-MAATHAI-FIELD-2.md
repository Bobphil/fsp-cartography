# FSP-VR-MAATHAI-FIELD-2

## Temporal Breathing; Present-State Zoom; Path-Borne Contingencies; Expanding Gates; Persistent Traces; Comparative Pinning; Reversible Temporal Zoom; and Field-Experience Regression

**Status:** NON-DEPLOYED EXPERIENCE-LAYER PROTOTYPE — VERSION 2  
**Parents:** FSP-VR-VISUAL-GRAMMAR-1; FSP-VR-MAATHAI-FIELD-1; FSP-VR-TEMPORAL-LENS-1; FSP-VR-FIELD-EXPERIENCE-REVIEW-1  
**Historical semantics:** unchanged from FIELD-1  
**Primary purpose:** Improve experiential continuity and geometry before adding new Maathai history.

# 1. Governing Rule

FIELD-2 changes interaction and geometry, not the canonical historical scene.

It adds an experience layer:

**TEMPORAL MODE → VIEW TRANSFORM → PATH DECOMPOSITION → TRACE MEMORY → COMPARATIVE FIELD → RETURN**

# 2. Temporal Breathing

Temporal changes must animate.

FREEZE:
- zoom inward toward the present;
- enlarge the near field;
- separate near loci;
- reduce distant-path salience continuously.

ACCELERATE:
- zoom outward;
- expand the horizon;
- reveal prerequisite chains before distant endpoints;
- preserve the center as the historical anchor.

Mode change must use interpolation rather than an abrupt visibility switch.

# 3. Present-State Zoom

Freeze trades temporal breadth for relational depth.

Freeze must increase inspectability of:
- near loci;
- local relations;
- source status;
- immediate constraints;
- path prerequisites.

> **Freeze should deepen the present, not merely hide the future.**

# 4. Path-Borne Contingencies

Each path may display its requirements as ordered beads positioned between the central locus and the path endpoint.

Requirement states remain:

- PRESENT;
- PARTIAL;
- ABSENT;
- UNKNOWN.

The bead sequence makes logical depth visible in the field.

# 5. Expanding Gates

A gate sits at the first materially unresolved requirement for a gated path.

Selecting the gate expands its nearby requirement beads and visibly interrupts the path.

The user should be able to see:
- where the path stops;
- what is missing;
- what remains unknown;
- which conditions are already present.

# 6. Persistent Traces

Every inspected path enters trace history.

A path can be pinned.

Pinned paths remain foregrounded across temporal-mode changes even when their terminal endpoint lies outside the current focal depth.

Out-of-range pinned paths become ghost traces rather than disappearing.

# 7. Comparative Pinning

Up to three paths may be pinned.

The comparison view shows:
- temporal depth;
- unresolved requirement count;
- contingency burden;
- absent requirements;
- unknown requirements.

Comparison must not rank paths by desirability.

# 8. Reversible Temporal Zoom

Moving:

**FREEZE → SLOW → NORMAL → ACCELERATE → FREEZE**

must preserve:
- pinned paths;
- trace history;
- expanded gate state where still meaningful;
- the anchored 1976 locus.

# 9. Renderer-State Separation

Experience state is projection-local:

- temporal mode;
- focus scale;
- pinned path IDs;
- selected path ID;
- expanded gate path ID;
- trace history.

None becomes canonical historical content.

# 10. Field-Experience Acceptance Target

FIELD-2 aims to meet:

- E1 Anchored Present ≥ 1
- E2 Continuous Temporal Expansion = 2
- E3 Near-Field Decomposition = 2
- E4 Contingency Growth = 2
- E5 Gate as Threshold = 2
- E6 Persistence / Trace ≥ 1
- E7 Reversible Temporal Movement ≥ 1
- E8 Situated Comparison ≥ 1
- Total ≥ 12 / 16

# 11. Claim Ceiling

Passing code-level experience criteria does not establish that human users will experience the field as intended.

A framework-naive visual study remains required.
